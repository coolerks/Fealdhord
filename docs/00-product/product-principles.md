# 产品原则

- RSS 独立成立：没有 Provider、API Key 或网络时，已缓存内容、状态、分类与搜索可使用；新增抓取需要网络。
- 本地数据为主：SQLite 保存领域事实；模型只收到当前操作所需的最少内容。
- 双视图同等重要：真实列表、动态瀑布流、首图提取与动效从 Shell 阶段开始验证。
- 可理解与可撤销：危险工具必须展示具体目标后确认，乐观状态失败要恢复，动画不掩盖错误。
- 阅读优先：克制、高信息密度、清晰排版；不复制参考产品界面，不用假数据冒充完成。
- 安全边界一致：前端、Agent 与 MCP 经同一应用服务和权限检查，文章文本不能提升权限。
- 事实可追踪：官方事实、项目方案、未验证假设分开记录；不凭依赖存在认定能力已完成。
- 中文是项目说明语言；技术标识符保持稳定。
