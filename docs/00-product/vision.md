# 产品愿景

折栈 Fealdhord 是本地优先的 AI RSS 阅读器与 Agent 工作空间。主要用户是长期阅读技术、设计和行业内容、需要掌控订阅与阅读记录的个人桌面用户。核心结果是高效订阅、发现、阅读、组织与回顾信息。

第一条完整用户旅程是不配置 AI：添加订阅 → 刷新 → 列表扫描或瀑布流浏览 → 阅读 → 分类／收藏 → 搜索找回。第二条是用户主动配置模型后：在文章、分类或全局上下文中总结、翻译、组织内容，通过有权限控制的工具完成真实操作。

长期方向保留更多模型、Skills 和 MCP 的扩展点；不以云账号、多人协作或向量数据库作为基础体验的前提。产品中的 Agent 能力与开发方式无关：仓库开发禁止辅助代理，产品 Agent Runtime 仍在长期范围内。
