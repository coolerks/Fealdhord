# 版本范围与冲突处理

## 当前工作范围

规格阶段已交付中文需求与技术文档。用户在最终摘要后明确授权开始实施，当前执行 Phase 0 桌面工程子任务；后续产品能力依原阶段顺序推进。拟定规格不自动转为已实现。

## 阶段范围

| 阶段 | 用户结果 | 必备范围 |
| --- | --- | --- |
| RSS 基础版：Phase 0–4 | 无 AI 也能完整订阅和阅读 | Shell、双视图、首图、数据库、RSS／Atom／JSON Feed、分类、OPML、搜索、Reader、主题、键盘、动效 |
| AI 增强：Phase 5–8 | 可选择模型理解与操作内容 | 三协议流式和非流式、分类／精选、Chat、Runtime、权限、内置 Tools |
| 扩展与发布：Phase 9–12 | 安全组合技能和外部能力 | 声明式 Skills、MCP Client／Server、五平台验证与发布 |

不配置 AI 时，精选展示解释性空态和配置入口；不生成假精选、不联网调用模型，不影响全部／未读／收藏。各后续 AI 入口在未配置时明确不可用原因。

## 明确暂缓与不支持

首轮不包含云同步、账号系统、移动端、Embedding／向量库、任意代码 Skill、插件市场和复杂 Workflow Designer。禁止旧 `/v1/completions`、Prompt JSON 模拟工具调用、Skill 执行脚本、前端解析厂商 SSE 或持有持久密钥。暂缓不等于永久删除需求；未来进入独立 ADR 与任务。

## 冲突优先级

1. 当前用户明确指示与根目录项目约束：中文文档、当前仅调研规格、禁止子代理。
2. 已验证官方技术事实；与原始指定冲突时记录 ADR 和风险。
3. 原始五十五-A 至 E 的双视图／媒体／动效细化优先于宽泛旧描述。
4. 其余原始章节；设计建议数值可通过实际实验修订并留痕。

Wails v3.0.0 官方要求 Go 1.26+，因此拟将实现最低版本提升为 1.26，满足原文 1.25+ 的下界意图；不能宣称 Go 1.25 可以编译该依赖。原文多 AI 协作仅保留可交接文档，不启用并行代理。Phase 12 是验证收尾，不是推迟 Phase 1 视觉与动效的理由。

## 默认方案的地位

列表为首次默认视图；主题跟随系统；动画 Full 且默认尊重系统减弱动态；远程图片仅订阅关联内容、网页补图关闭；按时间倒序；打开 Reader 后标记已读。这些是可逆首版设计建议，在设置和后续最终评审中可修改，不伪称来自用户逐项确认。
