# 声明式 Skill 规格

Skill 使用 `SKILL.md` 的 YAML 前置区与 Markdown 正文。要求小写字母、数字、短横线组成的 `name` 和非空 `description`。可用 `allowed-tools` 或旧 `tools` 声明进一步收窄本轮已有的工具权限。

设置支持导入、预览、编辑、启停和删除。ZIP 支持根目录或一个顶层技能目录内的单个 `SKILL.md`，同包脚本和二进制资源按相对路径保存。压缩包限 64 MiB，解包总量限 256 MiB，单文件限 64 MiB，最多 2,048 个条目和 16 层路径。说明文件最多 256 KiB。路径穿越、链接、特殊文件和冲突路径拒绝导入。预览提供文件名及大小，确认后发布版本。旧文本 JSON 安装可继续使用，编辑保存时迁入目录。

全局聊天初始仅发送启用 Skill 的名称、描述及逻辑入口。模型用 `read` 读取 `skill://名称/SKILL.md`，激活后才能访问该 Skill 的参考资料。文本资源分页返回，二进制跳过。脚本作为文件存储，可通过 `shell` 按本轮工具审批规则运行。

## 验收

- 安装和重启读回包含脚本、长文本与二进制的 ZIP，旧版 Skill 可按原名称使用。
- 模拟模型验证目录、说明和资源按需出现，工具权限和文件路径仍按本轮范围核对。
- 大文件读取遵守 2,000 行和 50 KiB 并可继续读取。
