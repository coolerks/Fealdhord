# 原生菜单与阅读体验契约

## 1. 范围

用户于 2026-11-04 明确否定绿色与邮件式常驻三栏，要求参考 macOS Books／Podcasts 的中性材质、留白与清晰内容层级。本契约覆盖此前对应视觉选择；原始需求快照不改动。

## 2. 签名

internal/desktop.WindowOptions／InstallMenu；事件 fealdhord:command={id:string}，已注册生成类型。前端 native 适配 Wails System／Window／Clipboard／Events，commands.runCommand 为白名单执行器。ApplicationMenu、Palette、工具栏和上下文菜单消费同一命令及 Query／UI 状态。

## 3. 契约

macOS 使用系统菜单栏：折栈／文件／编辑／显示／文章／窗口／帮助。编辑、隐藏、退出、全屏等采用原生 role，菜单快捷键遵守 Cmd；Windows／Linux 使用 Radix Menubar，自行实现文件／编辑／显示／文章／窗口／帮助，F10 可聚焦。Windows 采用自绘窗口栏，侧栏开关在菜单栏左端，最小化、最大化或还原、关闭位于右端，空白区域可拖动。最小化、最大化或还原使用中性的悬停和按压底色，关闭使用红色反馈。Linux 保留系统窗口框架。OPML 已于 Phase 4 接入系统／应用文件菜单与命令面板，通过设置分区调用原生文件授权。

macOS HiddenInset 隐藏标题文字并保留原生控制，NSVisualEffectView 窗口材质＋透明 HTML／WebView＋侧栏半透明叠色，主内容不透明；不使用私有 API。顶部预留 52px 控制／拖动区域。

列表视图在侧栏右侧固定并排显示文章列表与阅读区。瀑布流选择文章后默认铺满右侧区域，可在阅读排版切换抽屉。主题采用中性黑白灰。

全局 Radix ContextMenu＋DefaultContextMenuDisabled 禁止原生浏览器右键。文章菜单按目标 ID 操作；文本选择／输入提供复制、剪切、粘贴、全选。剪贴板异步写回前检查输入快照未变，尊重只读和 maxLength；失败明确提示，不能把命令当成功。文章标题、来源和正文可选择，表单字段保留原生文本编辑。普通界面文本禁用选择，应用全选限制在正文或编辑字段。

lucide-animated（MIT）官方 registry 源码按图标保存在 components/icons，并保留 LICENSE；原版轨迹不自创替换。AnimatedGlyph 从父按钮／菜单整行／键盘焦点触发，被动图标响应自身 Hover。播放完成后等待 normal／initial 归位再卸载，持续悬停不循环，移出不截断；同轮事件不重复启动、不排队。Full 才创建实例；Subtle／Off 静态，Provider 覆盖全局菜单。静态 SVG 由 npm run icons:generate 从同份库源生成，保持几何一致；正文与虚拟定位不受影响。

## 4. 校验与错误

未知菜单事件 ID 忽略；窗口／剪贴板失败显示安全错误。菜单未接领域功能明示禁用或跳转已有阶段说明，不展示伪数据。减少动态优先级沿用偏好契约。多阶段内部动画以 generation 中断，防止卸载或模式切换后旧 Promise 再次启动。

## 5. 案例

正常：macOS 显示菜单选择 Masonry，工具栏与持久偏好同步。基础：空白右键展示应用菜单，未出现浏览器后退／重载／检查。异常：选中文本后菜单夺焦导致粘贴目标丢失；必须使用打开前的目标快照。

## 紧凑窗口工具栏

文章浏览与阅读面板共用 50px 顶部工具栏，操作贴近视图右上缘。全部、未读、收藏、精选、分类和订阅使用同一浏览工具栏，列表与瀑布流切换保持其位置。窄分栏让操作留在顶部，标题放到下方。侧栏展开时，折叠按钮位于侧栏右上角。收起时，导航整列隐藏，内容区铺满窗口，同一个按钮移到标题栏左侧，macOS 上紧邻原生窗口按钮。侧栏和文章工作区沿水平方向同步平推，右侧超出窗口的部分由窗口容器裁切。收起起始时释放侧栏占位，展开结束时恢复占位，每次切换只改变一次内容布局宽度。过渡遵循动效偏好。浏览标题统一为 14px。可拖动区域避开交互按钮。设置各分区共用紧凑页头和右上角关闭入口。

初始窗口按显示器工作区调整，宽高分别最多占工作区的 90%。macOS 目标尺寸上限为 1240 × 800 点，首次显示前由 AppKit 在目标屏幕的可用区域居中。普通可缩放窗口在边缘 5 点内显示系统缩放光标，macOS 15 及以上按边和角显示对应方向，早期版本使用水平与垂直光标。边缘视图仅注册光标区域，鼠标事件仍由 AppKit 与 WebView 处理。Windows 和 Linux 的目标尺寸上限为 1000 × 640。设置导航可独立滚动。

Windows 标题栏使用横线、方框和重叠方框，并同步窗口状态。Windows 使用 WebView2 合成托管，Wails 在宿主窗口处理边缘与角落的原生缩放命中测试。关闭按钮和文章滚动条沿用贴边布局。输入框和文本域打开右键菜单时保留选区提示。订阅预览与阅读模式共用文章排版，代码高亮按需加载，语言标记通过受限的 HTML 清洗规则保留。 未识别或超出高亮预算的代码保留原样。旧缓存没有语言标记时使用受限的自动检测。


## Windows 标题栏与侧栏材质

Windows 11 22H2（Build 22621）起，主窗口由 Wails 配置 DWM Acrylic 与透明 WebView2。自绘标题栏和侧栏共享同一半透明叠色，文章列表、阅读区与菜单弹层使用实色。低于该版本时使用实色原生窗口。WebView2 报告降低透明度、偏好高对比度或强制颜色时，标题栏与侧栏使用实色。保留 WebView2 合成托管的窗口边缘缩放。

实机验收时将窗口移过高反差的背景，分别检查浅色与深色下标题栏和侧栏的材质连贯、阅读区不透底，以及角落缩放、标题栏拖动和窗口按钮。关闭系统透明效果或启用对比度主题后检查实色回退。

分类与订阅区域有独立滚动区，四个阅读入口固定。滚动内容越过上边缘时显示细分隔线，回到顶部后隐藏。Windows 标题栏底部无常驻分割线，标题栏菜单、侧栏开关、系统导航、订阅及分类以半透明叠色区分悬停、按下和选中状态。分类的展开按钮与名称共用整行反馈。
