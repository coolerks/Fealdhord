# OPML 导入导出规格

Phase 4。原生文件对话框选择导入／导出目标；前端只持有授权 token。文件最大 10MiB、嵌套深度 16、Feed 数最多 10,000；XML 不解析外部实体、不发网络请求。

导入两阶段：解析预览（分类树、合法 Feed、重复项、坏 URL）→ 用户选择确认 → 事务保存。大小写归一的 xmlUrl 去重；同源出现在不同 Folder 时只建一个 Feed，多分类关联。空 Folder 保留分类；非 Feed outline 作为 Folder；缺 xmlUrl 且非容器记为跳过并解释。导入完成不会无界同时抓取全部源，进入有界刷新队列。

分类 parent_id 保留层级；重名按同父级复用或在预览显示冲突，禁止悄悄重建全部同名分类。取消预览零写入；导入失败本事务回滚，报告新增／复用／跳过／错误项及原因。

导出保留树形分类；多分类 Feed 在对应 Folder 重复 outline，无分类 Feed 放根级；再次导入恢复单 Feed 多关联。只导出订阅与分类，不导出密钥、阅读历史、API Provider 或内部路径。

## 验收

- OPML-01：嵌套、多分类重复、坏 URL、空 Folder fixture 正确；导出再导入保持订阅集合和分类关系。
- OPML-02：XXE／超限／过深被拒，预览不写库，取消不生成文件；导出失败保留已有文件。
