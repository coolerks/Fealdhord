# 阅读、收藏与阅读状态规格

设置「阅读排版」可选择点击文章打开订阅预览或阅读模式。订阅预览显示源提供的正文或摘要。可从阅读工具栏的「更多 → 阅读方式」子菜单切换订阅预览与阅读模式，当前方式在右侧打勾，或在设置中将两个图标标签页常驻。打开原文使用系统浏览器。旧的全文偏好会打开阅读模式。

列表和瀑布流打开的文章共用阅读工具栏。右侧默认常驻「重新提取正文」「收藏」「翻译」和「AI 助手」。刷新从订阅预览进入阅读模式并重新提取正文。末尾的「更多」默认包含「归类」「标为已读」或「标为未读」「阅读方式」「打开原文」和「工具栏设置…」。设置「阅读排版 → 常驻工具栏按钮」使用相同的操作名称和图标，支持搜索并勾选，取消勾选后移入「更多」。「标为已读／未读」配置同一项，阅读时按文章状态显示对应动作。返回操作固定在左侧。

首次呈现正文成功后默认标已读，搜索预览／鼠标经过不标已读；可在设置关闭。SetRead／SetFavorite 幂等；错误回滚界面，刷新内容不重置状态。正文不足时仍展示标题／摘要与原文入口，不能空白崩溃。

正文宽度默认 720px，设置范围 680–760px（窄窗口自适应）；字号默认 17px，可调 14–24px，行高默认 1.7，可调 1.4–2.0；字体选系统 sans／serif／monospace。代码块和表格在正文内部横向滚动，不能撑开应用。图片按策略加载，禁远程图时正文同样不发请求。

## 文章翻译

阅读工具栏「翻译」菜单提供「双语对照」「仅看译文」「仅看原文」。默认值可在「阅读排版 → 译文显示方式」配置。切换显示和临时目标语言只读取对应缓存。菜单独立提供「翻译正文」「继续翻译」「重新翻译」与「取消翻译」。只有标题译文时仍可发起正文翻译。自动翻译保留当前显示方式。

「仅看译文」在已有译文的段落、标题、列表和表格中显示译文，保留正文结构、插图与代码块。尚未翻译的段落显示原文。切换回双语对照或仅原文时恢复原文字。

「文章 AI」设置分别控制新文章后台翻译、后台翻译范围与打开文章时翻译。订阅的「跟随全局」分别继承两项全局开关。选择「开启」或「关闭」会同时覆盖两项自动触发。后台范围始终可配置，订阅开启时也采用这个范围。

后台「含全文」先处理标题与摘要，再处理原网页正文。原网页提取失败时保留订阅预览译文，全文阶段稍后重试。标题或摘要已是目标语言时，正文仍会独立检查。

正文按模型输入和输出预算串行分批。可装入常规批次的短文一次处理。交互翻译长文优先翻译当前阅读位置附近最多三个短块，后续按原文顺序继续。首批译文保存后即显示，后续更新保留阅读位置。后台仍按原文顺序处理。

超长段落按句子和安全的文本边界切分，链接目标、内联代码和格式保留。所有片段完成后合成一个段落，阅读器的进度始终按完整正文块计数。漏段或截断时只有限补发受影响的内容。取消、限流或关闭应用后，已经校验并保存的译文和片段可以续翻。重新提取正文后，匹配的段落仍可复用，过期任务的结果不会进入新的正文视图。

行内格式等效时沿用原文标签和链接。返回内容缺少必要格式时，补发可改用文本占位符，由本地恢复原结构。显示译文时会还原误转义的常用非 ASCII 字符，保留原文中刻意展示的实体和内联代码。

## 代码块

正文代码块左上角显示语言，右上角以紧凑图标按钮复制代码文本，保留缩进与换行。已有语言标记优先，无标记时使用有界自动检测，识别不可靠时显示「纯文本」。无法高亮或超预算的代码仍可复制。

「阅读排版 → 代码块主题」可按名称或标识搜索安装版本内的全部 highlight.js 主题，包括 Base16。默认「跟随应用」使用应用的深浅色主题。所选样式按需加载，只作用于阅读正文。

## 正文图片与目录

正文图片右键可复制图片到系统剪贴板。点击图片或聚焦后按 Enter 进入看图，图片从正文中的位置和尺寸过渡到看图区域，背景同步淡入。看图区域覆盖整个阅读面板。阅读标题和工具栏隐藏。点击底部缩放滑杆右侧的叉号或按 Esc 退出看图，恢复阅读工具栏、正文滚动位置和打开看图前的焦点。完整动效下，退出时图片缩回正文可见的对应位置，背景淡出。对应位置不在视口内时使用淡出。轻微动效只淡入淡出，关闭动效时立即进出。看图右键菜单可复制、放大、缩小、前后切换与退出。默认点击图片周围的空白处也会退出，可在「阅读排版 → 点击空白处退出看图」关闭。半透明缩放滑杆闲置后收起，键盘操作时保持可见。

鼠标滚轮默认连续缩放，图片已超出视口时仍可继续放大或缩小。也可在「阅读排版 → 看图时滚动鼠标」设为切换图片。放大到超出视口后，按住左键可抓取并拖动图片，松手结束拖动，拖动产生的点击不会退出看图。右键打开图片菜单。macOS 直接按 AppKit 的滑动和惯性阶段分流看图区域内的双指事件，使用系统提供的双轴增量，支持斜向和中途换向。图片适配视口时，双指滑动不改变缩放。触控板捏合或 Ctrl + 鼠标滚轮缩放图片，在滚轮切图设置下也可用。

完整动效下，切图等待目标图片就绪，再按上一张或下一张方向平推。底部控件保持原位。轻微动效与关闭动效时直接切换。

文章目录从当前正文的 H1–H6 生成。默认在阅读区左缘显示刻度。悬停或激活时，面板以完整宽度滑入并覆盖刻度，收起时反向滑出。选中标题后，短距离平滑滚动，长距离略过中段并在目标附近减速，焦点移到标题。关闭动效时直接显示或收起面板，并直接定位标题。目录项尾端用 Kbd 显示标题等级。固定目录位于正文左侧。自适应模式在阅读区至少 960px 时常驻目录，较窄时显示刻度。目录也可隐藏。没有正文标题时省略目录。

打开文章触发正文提取、切换到阅读模式触发提取或从工具栏重新提取时，正文区域显示骨架屏，文章标题与取消操作保持可见。完整动效使用脉冲动画，轻微动效和关闭动效使用静态骨架。提取成功后显示新正文，失败或取消后恢复之前的正文并提示原因。提取遵守登录和付费墙限制。选中文字只作为 Article Chat 的显式上下文。返回文章浏览时恢复选择、过滤、浏览锚点与 Reader 滚动位置；锚点文章已删除则按相邻排序项回退。

## 验收

- READER-01：离线已缓存内容可读，HTML 安全 fixture 不执行脚本／事件／危险嵌入；禁图零媒体网络请求。
- READER-02：已读和收藏跨视图同步、重启保留、失败回滚；Reader 提取取消保留订阅正文。
- READER-03：字体／宽度／主题变化仍可读，长代码／表格不造成应用横向溢出，关闭面板恢复原锚点。
- READER-04：正文与看图菜单复制当前图片，禁图策略生效。连续缩放、滚轮切图和 Esc 返回均可操作。图片溢出时左键拖动和双指斜向滚动可平移，拖动取消或失去捕获后清除抓手，松手后的点击不退出看图。右键可打开菜单，捏合只缩放当前图片。
- READER-05：目录只列正文标题，悬停展开后可跳转。固定、自适应、刻度和隐藏偏好可保存。

已接 Reader 白名单服务、安全订阅 HTML、本地资源 ID、显式网页提取／取消、独立缓存和系统浏览器原文／正文链接；相关菜单与命令面板接同一操作。Reader 内容按文章 revision 隔离，旧提取响应不能覆盖新正文，自动已读默认开启且可关闭，支持三类系统字体。正文图片最多32、链接最多256，超出不发请求；部分旧 RSS HTML 因原清理器曾剥离图片，需要下次源刷新后才有内嵌图片。

缓存离线读取和版本隔离由真实SQLite测试覆盖，完整原生离线重启／图片布局锚点与帧率尚未实机验收，不据组件测试承诺平台性能。

阅读模式进入时自动复用当前文章版本的缓存，缺缓存才提取。切走或关闭会取消未完成的提取，失败或取消保留订阅内容。工具栏切换只影响当前打开的文章，下次打开使用设置默认值。
