# AI 工具平台的当前配置与行为

全局 AI 聊天通过官方 OpenAI Go SDK 的 HTTP 与 SSE 基础能力调用 Chat Completions、Responses，通过官方 Anthropic Go SDK 发送 Messages 请求。项目保留兼容网关扩展字段、终止事件校验、取消及超时。工具与 MCP 使用官方 Go SDK 的 Streamable HTTP 或 stdio，复用同一应用工具执行入口。

## 模型与上下文

- 服务目录优先提供模型 ID、显示名称、窗口、输入类型和适用价格。Models.dev 与 Pi 补充缺失资料，只向固定公共目录下载并缓存。匹配时从最完整模型 ID 逐层去掉路由前缀，模型调用保留配置中的完整 ID。公共目录价格标为参考价。
- 设置中可以手动填写上下文与输出上限，按厂商自动匹配或手动选择图标。图标首次缺失时从固定站点读取，安全检查通过后本地缓存，读取失败时使用通用图标。模型列表次行显示服务商、输入模态图标和简写上下文容量。悬停模型信息区或编辑模型可查看完整窗口、最大输出、计价和来源。
- 全局 AI 输入栏的圆环按历史及摘要占输入预算的估算比例绘制。悬停查看估算占用、已用令牌、输入预算和模型窗口，点击打开上下文管理。模型或会话切换、回复结束及修改上下文后刷新用量。重置时保留可见聊天记录，并从当前消息之后构建新的模型上下文。可以手填续聊摘要，也可以临时调用当前模型生成并审阅摘要，确认重置后才保存。恢复操作会重新纳入原历史。
- 请求和工具续传根据选定模型独立计算预算，优先移除完整的旧轮次，保留最新输入和工具调用对应的结果。原生 Anthropic 服务在接近预算限制时调用计数接口，其他服务用本地估算；面板也显示上一轮服务报告的令牌数（若提供）。每次最多从最近 200 条消息选择完整轮次。工具目录占用较小窗口的大部分预算时，聊天通过两个精简入口查询和调用已授权工具，沿用原审批。
- 打开「附加文章」搜索并显式引用，或直接在聊天里请求查找本地文章。有会话后可在上下文面板固定最多三篇文章的摘要，移除后停止自动附加。固定范围只涵盖摘要，读取正文另行授权。启用自动整理后，预算裁剪旧轮次时可以调用当前模型压缩，摘要成功时保存断点，失败时本次按已有预算继续。

- 会话列表读取失败时保留已经加载的条目。历史查询不配置失败自动重试、窗口聚焦或网络重连刷新；进入工作区及会话操作仍按正常流程读取。

## 输入框命令

- 全局 AI 空白输入框输入 `/` 可选技能、新对话、附加文章、模型、思考档位、上下文及 AI 设置。可继续输入命令名或关键词筛选，用方向键与 Enter 操作。Esc 返回上一级或关闭命令菜单。
- 菜单动作更新现有界面或设置，选中的技能显示在输入区并随消息发送。普通路径和链接继续按文本发送。

## 工具与 Skills

- DeepSeek V4 的兼容 Chat Completions 会话支持同时选择思考档位和使用工具。当前回复的工具续传沿用同一档位，推理字段只保留在当前生成的内存中。其他已知不兼容的档位与工具组合会在发送前提示。

- [工具清单](../../.trellis/tasks/11-21-ai-tool-platform/tools.md)列出 44 项能力及其已有业务入口。读取正文、修改订阅/分类、调用可能付费的操作等需要桌面确认。文章及订阅读取剔除链接凭据、查询串和非必要图标。原文章助手已有的明确授权读取继续有效。
- 审批持有原始参数，桌面只提交动作 ID 与是否允许。待确认最长两分钟，拒绝、取消、超时或重启后的预执行动作会失效。执行记录仅存主体、名称、时间和结果状态，可在 AI 设置查看，不持久化参数和工具正文。
- 「设置 → 工具权限」按内置功能域与外部 MCP 连接分组展示工具规则，支持关键词搜索、来源与「已自定义」筛选、逐项四段切换（默认、放行、需要审批、拒绝）、整组批量设置以及二次确认后恢复全部默认；「服务与模型 → 工具审批」选为「自定义权限」时提供直达入口。全局聊天选择「自定义权限」后，每次发送使用已保存的规则快照。未配置的工具使用原有审批要求。会话的其他审批模式沿用各自行为。显式放行也须满足参数、技能或正文数据授权。MCP 服务端的外部客户端继续使用独立授权。
- AI 设置支持导入、预览、编辑、启停和删除 Skill。说明和目录的加载契约见[声明式 Skill](skills.md)。全局聊天支持分组目录和按需创建的普通会话目录。详见[聊天与会话分组](chat.md)。
- 全局 AI 提供 `read`、`write`、`edit`、`shell`。文件工具使用本轮授权目录，`read` 返回真实行号和续读位置，`write` 补齐父目录，`edit` 支持唯一匹配或显式 `replaceAll`。目录列表和搜索用 `shell`。本地工具仅通过全局 AI 运行。
- `shell` 每次使用现有的单次桌面审批，展示完整命令和实际工作目录。批准后以当前桌面用户身份执行。工作目录决定启动位置，进程使用已批准的主机用户权限。命令超时或取消会停止受管前台进程，审批失效时无需启动。命令输出有上限。

「添加 Skill」预填可直接保存的示例，包括名称、描述和 Markdown 正文。示例名称避开列表中的已有名称。用户可修改正文以定义自己的操作指令。

## MCP 双向接入

- 在「设置 → MCP」的「MCP 服务端」保存端口、公开工具和启用状态。关闭本机外接入时监听 `127.0.0.1`，开启后填写本机的一个指定监听 IP。启用 HTTPS 时填写本地证书和私钥路径，客户端用受信任且匹配该 IP 的证书连接。在已授权的私有网络范围也能使用 HTTP。
- 服务端通过 `/mcp` 提供 MCP Streamable HTTP。可在保存允许的工具后为每个客户端指定允许的工具子集并生成独立 Bearer 令牌，也可使用默认令牌访问公开列表。还可以将独立客户端限制到某个订阅或分类。「公开工具」与「允许的工具」支持按名称或用途搜索，悬停选项时在侧边显示工具描述和适用的审批要求。授权变更或撤销即时影响新请求并取消旧授权等待中的调用，桌面审批仍适用于受限操作。允许对应工具的客户端可以读取文章摘要、订阅和分类的资源模板。
- 启用 TLS 时校验证书有效期与监听 IP。保存同地址同端口的 TLS 或证书变更失败时，已运行的入口继续服务。成功切换协议后，原协议的连接拒绝后续请求。撤销最后一个独立客户端后，服务继续监听并拒绝未授权请求，重启后仍保留撤销状态。
- 编辑客户端授权可修改工具及数据范围，原 Bearer 令牌继续有效。创建或主动更换后，新令牌只在本次设置会话中显示于对应的客户端行。更换须先确认，成功后旧令牌立即失效。
- 「外部 MCP 连接」支持中文显示名称。改名保留连接标识、旧凭据及同一目标的工具权限。重连或编辑失败时保留上一次保存的配置和可用连接。工具列表读取所有分页，每连接最多接受 4096 个工具、1024 页和 16 MiB 目录，超过限制或发现重复游标时报告错误。连接列表支持搜索长工具列表。全局聊天可调用已连接服务的工具、文本资源和提示词，默认需要确认。自定义规则按连接、目标和工具区分，重连同一目标后继续适用。暂时不可用的规则仍可清除。
- STDIO 支持命令、逐行参数、环境变量和工作目录。高级设置可调整启动超时、工具调用超时和日志等级，默认分别为 15 秒、120 秒和警告。日志等级用于支持 `logging/setLevel` 的服务。连接行的「查看日志」显示最近的 stderr 和 MCP 日志，断开后仍可查看。首次启动失败也可在编辑窗口查看启动日志。每个缓冲区最多保存最近 100 条，过长记录省略，日志仅留在本次应用运行的内存中。
- Streamable HTTP 支持 URL、请求头，以及高级设置中的连接与工具调用超时、HTTP 代理地址和端口、可选代理认证、HTTPS 证书验证和连接重试。两个超时默认 120 秒，连接默认重试 3 次，设为 0 时关闭重试。代理留空时直连，HTTPS 默认验证证书。工具调用超时后保留结果未知状态，连接重试不重放工具调用。
- 支持在连接文本参数中使用 `${NAME}`。建连时从折栈进程的环境读取，缺少变量则提示变量名。请求头、环境变量值和代理密码由系统凭据库保存，编辑器可显示单独的变量引用。旧 Bearer 在成功重新保存时迁移为 `Authorization` 请求头。日志采集会遮盖当前连接已知的环境引用、配置凭据和可识别的凭据字段。

测试覆盖本机 HTTP 和 HTTPS、允许接入地址规则、客户端工具和数据范围、审批消费、预算裁剪、上下文重启恢复及 Skill 包路径检查。需要 OAuth 自动发现的第三方客户端仍待专项对接。真实供应商和跨设备 HTTPS 尚无实测记录。部分兼容网关在显式思考档位下仍只支持纯对话，工具调用需使用可兼容的档位。
