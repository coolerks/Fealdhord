# 全文搜索规格

Phase 4；本地离线 FTS5，索引标题、作者、摘要和正文。支持 Feed／Category／已读／收藏过滤，默认相关性排序，也可时间排序。搜索与列表使用统一 ArticleQuery 和摘要分页。

查询最长 512 字符，去首尾空白；空查询返回当前 scope 普通列表。首版是字面搜索，空白分隔词 AND，用户输入引号、冒号、星号等不直接拼成 SQL 或 raw MATCH；由受测编译器转义并构造参数。中文二字片段与单字 token 及连续文本校验见调研；中英混合每部分都需匹配。

返回安全文本摘要与命中范围，React 按片段标记，不注入未经清理的 snippet HTML。权重拟定 title=5、author=2、summary=2、content=1；相关性同分再用 sort_at／id 排序。全文 index generation 改变时旧 rank 游标失效并恢复 article_id 锚点，不混合两个索引快照。

键入防抖 150ms，可取消，旧响应不能覆盖较新词。损坏索引提示可重建，基础文章仍可读；不能把 FTS 失败静默转全表无界 LIKE。中文单字有候选上限并提示缩小范围，性能指标见质量文档。

## 验收

- SEARCH-01：中英、双字“并发”、单字“栈”、标点、空词和组合过滤有确定结果，无 SQL／FTS 语法注入。
- SEARCH-02：新增／改文／删文同事务同步索引；重建后结果一致，中文片段假阳性被过滤。
- SEARCH-03：分页不重复／漏页，旧查询不盖新查询；100k 规模实际测量后才宣称性能通过。
