# Chat 与上下文规格

Phase 5 提供无工具基础聊天；Phase 7–8 开启受控工具操作。聊天是增强入口，不替代订阅和阅读主界面。

Global Chat 使用显式检索；Category Chat 固定当前分类有效成员 scope；Article Chat 包含当前文章和用户选中文本。默认不自动读取全库。UI 在发送前显示 scope、模型与启用 Skill，可移除选中内容；切换文章不能悄悄修改正在运行的请求快照。

消息保存本机，流式文本、工具状态、审批与错误分开展示。发送后可取消；取消保留部分输出并标记未完成。未配置模型有配置入口，原文阅读不受影响。使用的文章引用链接到本地 article_id，模型编造 ID 不生成可点引用。

总结、解释、翻译使用对应模型分配；“收藏／加入分类”必须经 Tool，不把语言回复当操作成功。流式自动滚动只在用户本来位于底部时进行，用户向上阅读不被强拉回。重开会话读取快照，不恢复执行写操作。

## 验收

- CHAT-01：三种 scope 有可观察差异，发送内容受最少上下文与预算限制。
- CHAT-02：文本流、取消、错误、工具多调用与待审批状态可区分；失败不能显示“已收藏”。
- CHAT-03：不配置 AI 仍可完整 RSS 使用；流式到达不改变 Reader 的滚动位置。

## 已交付的桌面对话

侧栏、分类工具栏和文章阅读面板进入独立会话范围。发送前显示聊天模型。分类可主动附加最近五篇有效成员的摘要，文章可主动附加订阅正文，并可移除从当前文章带入的选段。全局对话可在本地显式搜索并选择最多三篇文章，发送时仅加入已选文章的标题和有界摘要。搜索词和未选结果留在本地。附加的正文、摘要和选段只用于当前请求，历史仅保留用户输入与模型输出。读取聊天不会触发网络模型请求。

会话和消息存于迁移 00010。发送在一个事务内创建用户消息和助手占位，同会话只运行一条回复。运行中每秒保存新增文本，正常结束、失败或取消时保存当前内容，非正常退出后将遗留运行标记为中断。会话列表和消息快照分别返回最近 100 条。界面只在当前会话生成时每 250 毫秒读取一次快照，关闭后生成可在后台继续，重新打开可读取最新状态。工具执行和模型生成的文章引用解析待后续实现。
