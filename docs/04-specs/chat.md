# Chat 与上下文规格

每条 AI 回复左下角可复制正文、从该回复创建聊天分支，或打开详情。分支复制到所选回复并保留会话范围。详情显示本次耗时、首字耗时、平均输出速度、模型调用轮次、模型、思考等级和输入、缓存输入及输出 Token。用量按回复内的模型调用合计。首字耗时从后台生成启动计到首个非空白正文增量。平均输出速度采用最后一轮服务报告的输出 Token，除以该轮首个非空白正文增量到完成的时间。服务的输出计数可能包含推理 Token。缺少对应计数或时长时显示「未记录」。

生成中的回复隐藏复制、分支与详情。全局聊天收到的 Markdown 新文字以短片段错峰淡入，已显示的文字保持稳定，代码块持续即时更新。生成结束时清理动画节点。关闭应用动效或开启系统减少动态效果时，文字直接显示。

首字到达前显示带掠光的「正在思考」，减少动态效果时使用静态文字。有实际活动时，回复上方展示 API 提供的可读思考内容、摘要和工具活动。每项工具可展开查看调用参数与返回值。回复结束时自动折叠，标题以「用时」和整数小时、分钟、秒显示实际耗时。展开记录随消息保存在本机，旧回复仍显示已有的记录。切换会话前清除旧会话内的文字选区。

回复的思考、工具活动和正文按实际输出位置呈现。同一位置内的思考和工具继续按发生顺序显示。旧版本未保存位置的回复保留原有的聚合记录。

全局聊天的加号旁可选择「需要审批」「绕过审批」和「拒绝审批」。选择应用到当前会话之后发送的回复，设置里的默认值为「需要审批」。需要审批时默认用授权信息替换输入框，也可配置为对话框。处理后原草稿恢复。没有对应聊天输入框的审批通过对话框处理。

Phase 5 提供无工具基础聊天；Phase 7–8 开启受控工具操作。聊天是增强入口，不替代订阅和阅读主界面。

Global Chat 使用显式检索；Category Chat 固定当前分类有效成员 scope；Article Chat 包含当前文章和用户选中文本。默认不自动读取全库。UI 在发送前显示 scope、模型与启用 Skill，可移除选中内容；切换文章不能悄悄修改正在运行的请求快照。

消息保存本机，流式文本、工具状态、审批与错误分开展示。发送后可取消；取消保留部分输出并标记未完成。未配置模型有配置入口，原文阅读不受影响。使用的文章引用链接到本地 article_id，模型编造 ID 不生成可点引用。

总结、解释、翻译使用对应模型分配；“收藏／加入分类”必须经 Tool，不把语言回复当操作成功。流式自动滚动只在用户本来位于底部时进行。向上阅读时，「回到最新」按钮悬浮在消息区底部，点击后恢复跟随。生成状态由输入区的停止按钮表示，失败、取消和中断仍在消息旁显示。重开会话读取快照，不恢复执行写操作。

## 验收

- CHAT-01：三种 scope 有可观察差异，发送内容受最少上下文与预算限制。
- CHAT-02：文本流、取消、错误、工具多调用与待审批状态可区分；失败不能显示“已收藏”。
- CHAT-03：不配置 AI 仍可完整 RSS 使用；流式到达不改变 Reader 的滚动位置。

## 已交付的桌面对话

左下角打开全局 AI 工作区。侧栏列出本地会话和「新对话」，底部左侧「阅读」切回原文章、范围与浏览位置，右侧齿轮打开 AI 设置。标题栏沿用阅读工作区样式，省略底部分隔线。侧栏收起时可从会话标题栏切回阅读。首条消息发送时创建会话。生成中的回复可在后台继续，重开会话后查看进度。

全局输入区右下方可按模型名、模型 ID 或服务商搜索已启用模型，界面标签显示模型名称。全局输入区记住最近一次显式选择的模型，重新进入 AI 或重启应用时恢复。已记住的模型不可用或尚未有选择时，使用配置中的默认聊天模型，再找不到则选择第一个可用模型。点击有档位的模型行，或在该行按 Enter／方向右键，可展开对应的思考档位子菜单。选中档位同时切换模型，未配置档位的模型可直接选择。空间不足时子菜单向另一侧展开。每次发送使用当时的模型和档位，使用服务默认时省略思考强度。已删除的选项提示重新选择。已知需要额外推理上下文才能续接工具的协议会提前拒绝显式档位与正文读取授权的组合，此时可改用服务默认或取消本轮读取授权。

全局 AI 回复将流式文本与历史消息渲染为 Markdown，包括标题、列表、引用、表格、链接和代码块。链接需由用户点击，通过系统浏览器打开。回复内的原始 HTML 不执行，远程图片只展示替代文字。代码块显示语言并提供复制。生成期间显示代码文本，结束后应用语法高亮。「AI 与扩展」中的「聊天代码块主题」可独立于阅读排版保存，缺省跟随应用。

分类工具栏与文章阅读面板继续进入各自的会话弹窗。分类可主动附加最近五篇有效成员的摘要，文章可主动附加订阅正文，并可移除从当前文章带入的选段。全局对话可在本地显式搜索并选择最多三篇文章，发送时仅加入已选文章的标题和有界摘要。搜索词和未选结果留在本地。附加的正文、摘要和选段只用于当前请求，历史仅保留用户输入与模型输出。读取聊天不会触发网络模型请求。

会话和消息存于迁移 00010。发送在一个事务内创建用户消息和助手占位，同会话只运行一条回复。运行中每秒在后台保存新增文本，正常结束、失败或取消时保存当前内容，非正常退出后将遗留运行标记为中断。会话列表和消息快照分别返回最近 100 条。界面订阅当前会话的正文增量，收到结束事件后读取最终快照。生成中每秒读取一次快照，补齐掉线或丢失的事件并更新工具状态。关闭后生成可在后台继续，重新打开可读取最新状态。工具执行和模型生成的文章引用解析待后续实现。

迁移 00025 为会话增加可空的置顶和归档时间。全局 AI 侧栏仅列出未归档会话，置顶组优先显示。右键分支以最近一条已结束的助手回复为分支点，打开独立的全局会话；逐条回复分支仍使用所选回复。归档保留会话、原消息和置顶状态。已归档会话仅在设置中分页列出，恢复后以原 ID 回到侧栏。删除清理该会话及其消息。正在生成的会话需要等待回复结束或停止后才可归档或删除。

### 旧库升级

早期开发库可能已登记上下文迁移却缺少 `conversations.auto_compact`。第 22 版升级先生成一致备份，再补字段。已有会话、消息、摘要和已有的自动整理设置会保留。此前缺少该设置的会话初始关闭自动整理。
