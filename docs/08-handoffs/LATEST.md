macOS 侧栏切换为 AppKit Sidebar 材质。通过 Wails 原生窗口句柄在首次显示前安装，前端只负责侧栏底色及实色回退。
macOS 的 Taskfile 与标签发布启用 Wails `private_mac_apis`，让 WebView 底色透明。

macOS 侧栏的导航状态使用统一的半透明底色，折叠按钮改为圆形浅底及细描边。

侧栏按钮恢复圆角方形。macOS 分隔条空闲时隐藏，保留拖动热区。侧栏宽度支持 220–360px，向左拖过下限 32px 后松手收起。

设置固定单选项统一为图标分段控件，菜单选项改为单行，分类分支新增高度过渡。

阅读布局默认铺满右侧区域，设置保留抽屉与宽窗口并排选项。重新提取正文统一由阅读工具栏触发。

列表视图固定并排显示文章列表与阅读区。列表和瀑布流复用订阅图标，并在日期前显示日历。
