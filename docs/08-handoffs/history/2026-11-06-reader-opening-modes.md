# 文章打开方式与应用内原文

「阅读排版」可设置点击文章时显示订阅预览或全文。全文默认方式可选原始网页或阅读模式。默认仍是订阅预览，选全文时初始默认阅读模式。右上角可立即切换，系统浏览器入口仍可用。

原始网页通过独立沙箱 iframe 直接显示站点提供的页面。站点拒绝嵌入或需要框架禁止的能力时，可以切换阅读模式或在浏览器打开。远程图片设为从不加载时不创建该框架，保留订阅内容。阅读模式沿用受控提取，先用版本对应的缓存，切走取消未完成的请求。

验证覆盖旧偏好兼容与保存、预览内容、自动提取、原网页沙箱、手动切换、取消和外部打开。桌面 HTTP 绑定中间件覆盖同源请求、外源、null Origin 和跨站 Fetch Metadata。macOS 开发实例的实际请求头已确认符合规则。原生页面渲染受重复窗口影响，本轮未完成实机确认。各网站能否内嵌由站点策略决定。
