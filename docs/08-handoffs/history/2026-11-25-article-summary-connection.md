# 文章摘要超时与连接失败

用户报告阅读器生成摘要时出现 `Timeout` 和 `ProviderConnectionError`。旧实现从进入队列起便计算两分钟总时限，长文各段和重试共用这段时间。模型连接失败或单次请求超时会立即结束。原始失败请求的日志只有绑定返回码。

排查时，已配置的网关 TCP 可达，HTTP 约 0.14 秒返回认证要求。使用应用的摘要配置和一篇合成短文，实际模型约 3.6 秒返回有效摘要。检查时网关可用，原始故障的网关状态和文章输入无法从两条绑定日志还原。

- 排队最多两分钟，取得执行槽后单独计算五分钟执行时限。每次模型请求最多两分钟。
- 遇到临时连接故障、单次超时、临时协议错误或可重试的 HTTP 错误，等待 300 毫秒后补发当前请求一次。与已有的输出修复共用这一次补发机会，仍受总输入预算及任务时限约束。认证失败和限流直接返回。
- 阅读器针对连接失败显示网络或模型连接检查提示，并保留手动重试入口。日志记录阶段、错误代码、耗时和重试状态，字段范围限于诊断所需数据。

## 验证

使用可控时钟复现排队接近两分钟、单次模型请求到期和取消补发。模拟临时断连验证成功恢复，持续断连仍返回原错误，认证失败和限流只调用一次。阅读器回归验证两类提示、正文仍可阅读以及手动重试。

Go 全量测试、静态检查和摘要包竞态测试通过。前端类型检查、lint 和生产构建通过，lint 保留现有的 TanStack Virtual 兼容提示。

前端首次全量运行有两项非摘要用例失败，涉及会话菜单和大型导入预览。两项单独复跑均通过。以两个 worker 重跑全量后，214 项全部通过。
