# 全局 AI 的默认 Shell 设置

- 「设置 → 工具权限」提供可搜索的默认 Shell 下拉框。列表按平台检测应用默认解释器及已安装的选项，未检测到的显式选项标为不可用。
- 设置保存到应用数据目录的 `shell-settings.json`。应用默认沿用 macOS／Linux 的 `sh` 和 Windows PowerShell，保留之前无需设置即可使用的行为。
- 每轮对话开始时解析已选解释器，同步更新模型看到的工具说明。审批展示解释器路径、实际工作目录和完整命令。用户批准后才执行，等待时解释器发生变化则停止。

## 验证

- macOS 命令执行回归涵盖新旧默认行为、设置重启后保留、对话期间快照、逐次审批、超时和不可用解释器。
- Go 全量测试、`go vet` 与 Shell 相关竞态测试通过。前端 216 项测试、类型检查、lint 和生产构建通过，保留既有 TanStack Virtual 与构建分块提示。
- Windows／Linux 已通过命令运行包的交叉编译检查，尚待在对应系统实际运行。macOS 验证使用真实的 `sh` 和 Bash 子进程，设置和审批界面通过前端组件测试覆盖。
