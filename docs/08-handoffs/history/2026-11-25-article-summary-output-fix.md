# 文章摘要输出修复

阅读器显示「摘要结果不完整，或重复正文，请重试」时，绑定日志只记录 `InvalidModelOutput`。该错误可由模型输出截断、JSON 格式不符或摘要与标题及正文重复过多触发。旧实现仅给摘要请求 480 个输出 token，并拒绝模型用 Markdown 代码围栏包裹的完整 JSON。

- 初次请求最多使用 2,048 个输出 token。遇到截断可在模型预算内增加到初次额度的两倍。摘要文字上限仍为 720 个字符。
- 解析时支持完全包住响应的一对 Markdown 代码围栏，围栏内必须是单个符合摘要协议的 JSON 对象。
- 格式、重复或截断问题在总输入预算内补发当前请求一次。长文只补发失败分段或最终合并请求。摘要仍需通过结束状态、内容压缩和长度校验，持续无效的结果不写入缓存。

## 验证

使用模拟模型和临时 SQLite 复现同一错误。完整 JSON 带代码围栏时首次成功。输出截断、格式错误或首轮复述标题时，重试成功并读回缓存。长文末段补发后保留关键事实，连续复述原文仍返回 `InvalidModelOutput`。用户遇到报错时的原始模型响应和桌面实测待确认。

`go test ./...`、`go vet ./...` 和 `go test -race ./internal/articlesummary` 均通过。全量测试仍有 macOS 测试二进制链接警告。
