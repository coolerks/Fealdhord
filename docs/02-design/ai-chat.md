# AI 对话与执行反馈设计

全局入口位于侧栏底部；分类可在分类标题操作中打开；文章通过 Reader 右侧 AI Panel。每次发送区域显示 scope、模型与 Skill，允许清除选中段落。未配置 Provider 显示设置入口，不用无限加载状态。

Chat 消息以文本阅读为主，工具折叠摘要与详情分开；正在调用、等待许可、成功、失败、取消、结果未知有文字与图标。审批卡显示实际目标、数量、影响、过期与确认／取消，危险操作按钮明确命名“确认归档 17 个订阅”，不能只写“继续”。

用户在流底部才跟随输出；向上阅读停止跟随并显示“回到最新”。Send 转 Cancel 的触控区稳定，取消立刻有反馈，最终状态以后端快照为准。复制部分输出时标注未完成，不把失败消息当最终答复。

验收 AIUI-01：纯对话、多工具、待审批、拒绝、过期、取消、重启恢复均有独立状态；键盘可操作审批和收起详情，运行活动指示仅在真实运行时持续。
