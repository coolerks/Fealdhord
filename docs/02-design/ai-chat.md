# AI 对话与执行反馈设计

全局入口位于侧栏底部。进入后侧栏显示会话与「新对话」，底部左侧切回阅读，右侧齿轮打开 AI 设置。右侧会话标题前显示 AI 图标。用户消息靠右，模型回复按 Markdown 排版，代码块可复制并采用聊天主题。输入框使用浅边线和淡阴影，附加文章在左，可搜索的模型和档位在圆形发送／停止按钮旁。模型名称与档位各用无边框触发按钮。分类从分类标题工具栏进入，文章从 Reader 工具栏进入，两者使用已有弹窗。

AI 侧栏采用阅读侧栏的行高、图标尺寸、间距和选中样式，操作图标沿用悬停与键盘聚焦动效。「新对话」和命令面板入口同样使用浅色边框和 Kbd。macOS 用 ⌘⇧N，Windows 和 Linux 用 Ctrl+Shift+N。快捷键只在全局 AI 工作区有效，打开空白对话并聚焦输入框。

会话行的右键菜单支持重命名、置顶或取消置顶、分支到新聊天、删除和归档。键盘聚焦会话后可用菜单键或 Shift+F10 打开。删除和归档各需确认一次。归档后可在「设置 → 已归档会话」恢复，或再次通过确认弹窗永久删除。

阅读与 AI 双向切换时，侧栏与主区域同步淡入淡出。完整动效附带短距离位移，轻微动效仅调整透明度，关闭动效时直接切换。退出中的区域退出键盘和鼠标交互，返回阅读恢复原文章和滚动位置。

「分组」「会话」标题的折叠箭头紧跟文字。各分组项以文件夹图标开头，点击名称所在行可展开或收起，行尾加号独立新建组内对话。普通和组内会话直接显示标题，置顶会话保留行尾标记。标题行、分组项和会话行的悬停与按压底色覆盖侧栏列表的整行，组内会话仅缩进文字。

分组允许覆盖默认文件夹图标和颜色。组内新对话在输入框下方显示使用相同图标的分组条，关闭按钮清除归属并保留草稿，提交前可重新确认目标。

全局聊天输入框左侧提供附加文章和审批方式。审批按钮显示当前模式文字和展开箭头，四个选项在展开后显示各自的图标。选择「自定义权限」时，根据「MCP 与权限」中为工具保存的规则处理调用。发送时按会话权限和所选技能提供工具。

Chat 消息以文本阅读为主，工具折叠摘要与详情分开；正在调用、等待许可、成功、失败、取消、结果未知有文字与图标。审批卡显示实际目标、数量、影响、过期与确认／取消，危险操作按钮明确命名“确认归档 17 个订阅”，不能只写“继续”。

用户在流底部才跟随输出；向上阅读停止跟随并显示“回到最新”。Send 转 Cancel 的触控区稳定，取消立刻有反馈，最终状态以后端快照为准。复制部分输出时标注未完成，不把失败消息当最终答复。

验收 AIUI-01：纯对话、多工具、待审批、拒绝、过期、取消、重启恢复均有独立状态；键盘可操作审批和收起详情，运行活动指示仅在真实运行时持续。
