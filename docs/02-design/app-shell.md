# 应用 Shell

Phase 1 首次运行即有玻璃侧栏、文章浏览区、Reader 与真实两种布局；占位仅表示尚无数据，不用假 Dashboard 内容。

宽屏默认三栏：Sidebar 248px（220–360），列表 360px（300–420），Reader 占余宽；分隔条支持拖动和键盘调整，以 settings 保存。窗口建议最小 900×600；低于三栏可读宽度时进入双栏，Reader 覆盖浏览区并有返回入口。分栏模式按容器宽度计算，不依赖显示器型号。

瀑布流进入宽浏览模式：保留 Sidebar、文章区使用余宽，自适应列数；选文打开右侧 Reader 抽屉，空间不足覆盖文章区。关闭抽屉返回原锚点。列表模式返回三栏布局并保持选择，不重发不同筛选查询。

顶栏包含当前 scope、文章数／刷新状态、搜索、筛选、排序、List／Masonry 切换；未实现入口应明确显示阶段状态，不伪装成功。侧栏底部 AI／设置，Reader 顶部原文／已读／收藏／AI。

macOS 顶栏使用共享的 54px 高度对齐折叠按钮、标题块与文章操作。篇数位于标题下方，窄栏保留两行重排。

加载态保留稳定骨架；空库引导添加订阅或导入 OPML；空结果提供清除过滤；失败保留上次内容并显示重试。视图状态恢复使用 schema_version 和合法范围校验。窗口标题栏拖动区不覆盖按钮和输入框。

验收 SHELL-01：最小／最大／缩放／高 DPI 下无应用级横向溢出；三栏、宽瀑布流、Reader 抽屉均可键盘返回，重启恢复有效布局。
