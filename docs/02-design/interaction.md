# 交互与键盘契约

焦点顺序：侧栏 → 文章工具栏 → 文章列表／卡片 → Reader → AI Panel。模态框限制焦点并在关闭后返回触发点；非模态 Reader 不抢走整个应用焦点。所有图标按钮有 accessible name／Tooltip／Focus-visible／Disabled。

| 快捷键 | 动作 | 边界 |
| --- | --- | --- |
| J／K | 下一／上一篇逻辑文章 | 非文本输入、非 IME 组合期间生效 |
| M | 设置当前已读／未读 | 无选择不执行 |
| F | 收藏／取消收藏 | 非输入区，失败回滚 |
| R | 刷新当前 scope | 真实运行期间合并请求 |
| / | 聚焦搜索 | 输入区不拦截 |
| Cmd/Ctrl+K | Command Palette | 全局入口，支持 Escape 关闭 |
| Enter | 打开选中文章／执行命令 | 不触发未知危险默认按钮 |
| Escape | 关闭最上层菜单／抽屉 | 有未保存内容时先提示 |
| Shift+F10 | 当前项目上下文菜单 | 与鼠标右键能力一致 |

Command Palette 包含搜索 Feed／Category、打开设置、刷新全部、添加订阅、切主题、打开 AI；命令调用相同应用服务，不绕权限。结果用键盘移动与 Enter 执行，无结果是真空态。快捷键冲突、平台保留键和输入法在五平台验证。

阅读操作的 Undo 必须对真实数据写回；快捷连点可以中断动画，不排队累积。DnD 有把手、目标线和取消，键盘有等价移动命令。错误 Toast 含原因和有意义重试，不抢焦点、不泄露内部错误。

验收 INPUT-01：全程键盘完成添加→搜索→阅读→收藏→返回；IME 输入、对话框和文本编辑不被单键快捷键干扰。
