# 玻璃侧栏

信息顺序：全部、精选、未读、收藏 → 分类树 → 订阅 → 底部 AI、设置。每项具有名称、Lucide 图标、必要未读数；超长名称截断并有 Tooltip，数字不挤占主要文字。

玻璃是信息层级：半透明表面、backdrop blur、低对比边框、轻高光、背后可见色层。Light 保持清晰，Dark 不堆重阴影；不依赖 macOS 私有材质。无 blur 或降低透明度时用稳定实色。Sidebar 是贯穿窗口的导航表面，不做浮动大 Card。

支持收起到图标栏 56px、分类展开、订阅组展开、右键菜单与拖动排序；展开状态和 sort_position 持久化。拖 Feed 到分类增加继承关联，预览目标与影响数量；拖树项只改变父级／顺序，拒环。所有拖动都有键盘“移动到…”替代入口。

方向键在树中移动／展开，Enter 选择，Shift+F10 打开上下文菜单。选中态有指示条和 aria-current；未读由数字／圆点表达。焦点与 Hover 均能看到同样操作。折叠后 Tooltip 不能替代 accessible name。

验收 SIDEBAR-01：Light／Dark／实色回退信息一致；键盘到达每个区域，未读数与共享 Query 一致，拖动可撤销或明确确认，不丢焦点。
