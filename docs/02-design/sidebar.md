# 玻璃侧栏

信息顺序：命令面板 → 全部、精选、未读、收藏 → 分类树 → 订阅 → 底部 AI、设置。每项具有名称、Lucide 图标、必要未读数；超长名称截断并有 Tooltip，数字不挤占主要文字。命令面板入口沿用阅读视图导航行的高度、左右边距与悬停形状。订阅行之间留 2px。

macOS 通过 Wails 创建透明窗口，由 AppKit 的 Sidebar 材质模糊窗口后方内容。前端只给侧栏叠加浅色或深色底色，正文区保持实色。启用降低透明度或提高对比度时采用实色侧栏，选中态和文字继续使用主题颜色。导航行、快捷入口和侧栏按钮的悬停与按压使用半透明叠色。阅读视图、分类和订阅共用更明显的选中底色，指针经过已选行时保持选中层级。折叠按钮使用默认透明、无描边的圆角方形，键盘聚焦时显示焦点提示。侧栏与正文直接衔接，分隔拖动区只在悬停、拖动或键盘聚焦时显示细线。

侧栏宽度为 220–360px。拖到最小宽度后再向左至少 32px 并松手，即可收起整列导航。重新展开恢复上次保存的宽度。键盘可用方向键调整，在最小宽度再按左方向键收起，焦点回到展开按钮。取消拖动不写入偏好。

后续设计包括分类展开、订阅组展开、右键菜单与拖动排序；展开状态和 sort_position 持久化。拖 Feed 到分类增加继承关联，预览目标与影响数量；拖树项只改变父级／顺序，拒环。所有拖动都有键盘“移动到…”替代入口。

方向键在树中移动／展开，Enter 选择，Shift+F10 打开上下文菜单。选中态有指示条和 aria-current；未读由数字／圆点表达。焦点与 Hover 均能看到同样操作。折叠后 Tooltip 不能替代 accessible name。

验收 SIDEBAR-01：Light／Dark／实色回退信息一致；键盘到达每个区域，未读数与共享 Query 一致，拖动可撤销或明确确认，不丢焦点。

分类行的悬停与选中底色覆盖整行。展开箭头独立响应点击和键盘操作，同层分类对齐图标，每深入一级向内缩进 16px。
