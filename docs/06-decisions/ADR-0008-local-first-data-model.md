# ADR-0008：本地事实源与分类覆盖

状态：拟定，待本轮规划评审；不是已完成实现。
日期：2026-11-04。

## 背景

AI 更新与源刷新不能覆盖用户阅读、收藏和分类意图。

## 决定

SQLite 为事实源，分类按 manual/feed/ai 独立存证，manual excluded 永远优先，精选独立 Smart View。

## 替代方案

单一 source 行覆盖和删除关系代替排除会让 AI 反复加回。

## 后果与验证

状态表独立，刷新只更新文章内容；模型上下文按需裁剪。
