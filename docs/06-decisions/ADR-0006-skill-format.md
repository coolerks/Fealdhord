# ADR-0006：声明式 Skill 格式

状态：拟定，待本轮规划评审；不是已完成实现。
日期：2026-11-04。

## 背景

需要可组合任务指导，但首版不引入任意代码运行。

## 决定

SKILL.md frontmatter v1 + 正文 + 安全 assets；tools allowlist 与策略取交集。

## 替代方案

脚本插件需要独立沙箱；把 Skill 当 Tool 会混淆指导与原子能力。

## 后果与验证

必须做路径／大小／版本校验，运行固定 manifest 快照。

依据与后续门禁：[相关规格／研究](../04-specs/skills.md)。
