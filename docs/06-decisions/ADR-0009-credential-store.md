# ADR-0009：系统凭据与内存 fallback

状态：拟定，待本轮规划评审；不是已完成实现。
日期：2026-11-04。

## 背景

三平台凭据设施不同，敏感扩展配置同样需要保护。

## 决定

CredentialStore 适配系统 keyring，DB 仅引用；服务不可用仅会话内存，不默认明文。

## 替代方案

明文 SQLite／配置文件方便但违背要求；自定义加密而密钥同文件无意义。

## 后果与验证

跨 keyring 与 SQLite 使用补偿策略，平台授权／锁屏／不可用需测试。
