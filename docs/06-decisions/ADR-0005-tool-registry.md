# ADR-0005：统一工具、权限与审批

状态：拟定，待本轮规划评审；不是已完成实现。
日期：2026-11-04。

## 背景

UI、模型与 MCP 必须共享业务边界，危险操作不能因模型回复而获准。

## 决定

统一 Registry／Executor，effect 与 external 组合风险；审批绑定参数、目标 revision、策略和期限。

## 替代方案

仅 UI 弹窗可被直接调用绕过；完全自动执行破坏性操作不可接受。

## 后果与验证

多工具有界调度、写串行；审批过期重新确认，外部未知结果不自动重放。
