# ADR-0010：共享数据的虚拟双视图

状态：拟定，待本轮规划评审；不是已完成实现。
日期：2026-11-04。

## 背景

双视图是一等能力，动态图片与列数变化必须保持顺序和锚点。

## 决定

同 Query、逻辑 DOM 顺序、虚拟定位与动态测量、article_id 锚点；禁止 CSS columns。

## 替代方案

两套数据缓存容易状态分叉；全部 DOM 无法支撑 100k。

## 后果与验证

TanStack lanes 原型必须验证，滚动期间抑制重排动效，不依赖库自动解决所有行为。
