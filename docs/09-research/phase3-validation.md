# Phase 3 RSS 验收记录

日期：2026-11-05。范围为本机 macOS arm64 的安全网络、订阅／刷新／媒体后端、现有界面功能接线；不进行视觉调整。

## 实际交付

- RSS、Atom、JSON Feed 本地字节解析，网页 alternate 发现与显式候选选择；缺标题／坏日期与纯文本安全回退。
- 添加、编辑名称／已有分类关联、改地址重新验证、归档和恢复；旧编辑 revision 冲突不会自动覆盖；归档保留文章和状态。
- 整源事务写文章／validator，304 不动文章；重复刷新保留身份、排序、已读／收藏／人工分类；限流信息跨重启保存。
- 有界刷新协调、同批合并、取消／部分失败、30 分钟到期检查；启动只补查到期源，不重放错过的时点。
- 受控 HTTP URL／DNS／拨号／逐跳检查，压缩前后大小限制；所有 Feed、网页及媒体共用网关。
- 首图候选／有限回退、JPEG／PNG／WebP 解码、像素限制与动画块拒绝；本地媒体 ID 路由、隐私取消、192MiB 磁盘＋64MiB 内存上限、7 天磁盘 TTL。
- 订阅设置、工具栏／命令面板／菜单刷新及 Cmd+R／Ctrl+R；活动任务取消、进度和失败数量；事件合并／快照恢复／Query 重取；图片策略、网页补图开关和缓存清理。
