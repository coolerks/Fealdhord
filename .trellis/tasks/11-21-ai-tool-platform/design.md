# 技术设计

状态：规划评审。整个任务作为一个发布及验收单元。保存现有会话/文章/模型 ID、模型分配、凭据引用、阅读与聊天入口。

## 1. 官方 SDK 与应用边界

React 通过 Wails 接入 Chat 与设置，MCP HTTP 客户端通过独立 MCP 端口接入。Chat Orchestrator 管会话和上下文，由统一 Tool Registry 与 Executor 调用现有 Library、Reader、Feed、Navigation、Refresh、Settings、Transfer、ArticleAI 或第三方 MCP Client。MCP Server 进入同一执行器。

OpenAI 两种协议用 openai-go，Messages 用 anthropic-sdk-go，保留 ModelRequest/ModelEvent 领域契约。SDK DTO 留在 Adapter 内，SDK 完成 HTTP、JSON 和 SSE，项目只做领域转换、权限与服务差异映射。SDK 客户端按已保存服务、配置 revision、凭据版本构建。显式配置原有服务地址和凭据，环境变量不能改变某个已保存服务的路由或密钥；运行使用启动时的连接快照。兼容网关通过 SDK 的 HTTP 客户端、Base URL、自定义路径、请求头、Query、扩展字段和禁用参数选项接入。扩展字段限制在配置的允许列表，不改写认证主体、工具、原始模型 ID 和预算。保留 OpenRouter 尾帧、思考强度、空闲/总时限、响应限额、取消、终态及用量语义。SDK 自动重试默认关闭，已经收到输出、产生写入或结果不明的轮次禁止自动重放。确因 SDK 不支持的兼容差异须先有回归，再以最小适配补齐并说明移除条件。

## 2. 模型身份与元数据

- 请求和历史使用原始 ProviderModelID，仅以独立 CanonicalModelRef 补资料。逐字段覆盖顺序为手动值、当前服务的目录值、Models.dev 对应托管记录和适用的基础模型字段、Pi 对应记录。保存来源、刷新时间、覆盖 revision；未知与明确不支持、零价分开。读取已配置 Base URL 的 /models，保留既有同源路径回退。已知网关分别解码 context_length、contextWindow、limit.context/input/output、top_provider.max_completion_tokens、模态与价格。负数、无单位价格或矛盾的上限视为无效字段。
- 匹配依次检查明确的用户匹配、当前供应商加原始 ID、目录提供的 canonical_model_id、完整作者/模型路径，最后尝试从最长到最短逐层去掉路由前缀。例：xxxx/xxx/claude-fable-5-2 还会尝试 xxx/claude-fable-5-2 和 claude-fable-5-2。版本日期、量化、免费/高速、窗口变体不能靠猜测砍掉。弱名称匹配只显示候选；同优先级多匹配时留空并允许手选。
- 区分上下文窗口、最大输入和最大输出。托管服务的线路限制优先于同名基础模型。价格以币种及每百万 token 显示输入、输出与可用的缓存费率，保留原精度。相同模型在其他服务商的价格只能标「参考」，套餐和实际账单不由目录推断。
- 公共目录通过固定 URL 后台更新。Models.dev 优先读取供应商与基础模型分拆目录，catalog.json 可作为合并索引。Pi 按供应商/模型解码。按 ETag、超时、退避、压缩/解压上限和原子写入保留最近有效快照。独立缓存公共目录、鉴权服务目录和图标。探测已有 403 与响应过大的证据，实施时验证按需刷新、初始化快照和失败回退；保存模型不依赖目录在线。公共请求只传固定路径，不发本机模型列表、凭据或会话。
- 图标按「用户指定 → 可确定的模型厂商 → 可信供应商 → 通用图标」取值。设置提供供应商/厂商搜索，可手选与恢复自动。常用且许可可用的图标随包安装，其余首次缺失或目录显式刷新时下载，按哈希本地缓存。拒绝 SVG 脚本、事件、外链、foreignObject，校验后栅格化或安全存为静态素材，前端通过本地资源 ID 显示。模型设置行和聊天模型菜单不因渲染发公网请求。
- 「AI 与扩展 → 模型」显示图标、输入能力的图标和可访问名称、窗口/输出及价格来源。编辑区允许手动覆盖窗口、输出、模态和图标。聊天模型菜单复用 SearchableSelect，保留已选模型记忆、长标签提示及档位子菜单。移除输入区上方独立搜索行，模型查文走工具，「＋」打开独立附加文章界面并保留可移除的附加项。

## 3. 会话上下文

- 持久状态含会话 scope、历史有效起点、已固定/排除的资料、摘要 checkpoint、所用模型/覆盖版本和记录来源。摘要存储覆盖轮次、来源 ID、许可版本及使用的模型；历史完整保留。支持查看、清理后续上下文、固定/排除资料、手动整理。模型切换后用新的窗口与输出上限重算，不能沿用之前的超量预算。
- 发送前和每次工具续轮构建真正的请求。输入预算取「最大输入、上下文窗口扣除生成预留与安全余量」的较小值。计入当前输入、系统内容、真实发出的历史、工具 Schema、Skill、工具结果、附件及引用。支持的路径用成熟 tokenizer 或供应商计数接口，其他路径用保守估算并用后续 usage 校准，界面区分估算和实测。供应商计数仅对本轮已授权内容发往已配置服务。未知窗口采用明确标记的保守应用预算，允许手动覆盖。
- 优先限制附件与工具结果；保留当前输入、必要指令、完整的最近轮和授权的固定资料。旧轮可裁剪或在用户允许时生成摘要，工具调用和对应结果一起保留或裁剪，避免残缺协议。自动摘要作为可控模式，仅在有预算时调用同一已授权模型，失败退回本地裁剪。摘要带来源，权限撤销后失效；已执行、待确认和结果未知必须保持各自语义。
- 面板展示可用窗口与来源、估算使用量、输出预留、资料、压缩和排除情况。必要内容本身超限时明确指出并让用户缩小输入。文章、分类和全局会话分别审查数据授权；检索先返回摘要与引用，读取正文只在授权范围。模型和外部工具文本不能改变该权限。

## 4. 工具与 Skills

统一 Registry 包含逻辑 ID、JSON Schema、风险、读写和外部副作用、数据范围、输出上限及真实服务函数。分别生成符合模型协议及 MCP 的 wire 名，检测冲突，记录统一逻辑名。按主体（Chat 会话或 MCP 客户端）、全局策略、工具、数据范围、Skill 允许列表取交集。读在授权范围内执行，写默认确认、破坏性操作始终确认；展示付费、外部网络和批量影响。单次上下文根据任务呈现可用子集，全部获准工具可搜索或按需发现。

审批保存永不可由前端重新提交的动作快照，含 action ID、主体、参数哈希、目标和 revision、策略版本、有效期。仅接收 ID 和批准决定，二次核验后 CAS 单次消费。读有界并发、写串行；同一次调用重复时返回已知结果。取消、拒绝、过期、冲突、重启均有明确状态；外部写结果未知时保留审计，不能自动重试。OPML 文件选择仅通过现有桌面授权。44 项及可复用入口见 [工具清单](tools.md)。

Skills 支持声明式 SKILL.md 与安全引用资源，兼容常用 frontmatter，遵循仓库既有边界。设置支持浏览、创建、编辑、复制内置、导入、启停、删除和依赖提示。导入限制深度与大小，拒绝不安全压缩包、路径穿越和符号链接逃逸；技能脚本不执行。运行取已授权工具和当前 Skill 白名单交集，按需注入、固定版本与内容哈希，删除/停用不影响已经启动的运行。用户显式启用的 MCP stdio 仍可启动其配置的独立程序。

## 5. MCP 双向接入

- Client 采用官方 Go SDK 接 stdio 与 Streamable HTTP，显式审阅可执行文件和 argv、网络地址和认证，凭据使用系统密钥库引用。发现 Tools/Resources/Prompts，管理连接状态、逐工具权限、取消、断线和重连。服务工具同名以连接稳定 ID 隔离；Schema/风险变更需要重新复核已有授权，远端注解不能扩大权限。带副作用的外部调用经过统一审批。外部资源和提示词都作为有界、可选内容。
- Server 默认关闭，首次启用时「允许本机外接入」默认关闭，使用官方 Streamable HTTP。设置提供端口、「允许本机外接入」与「启用 TLS」两个独立开关。关闭外部接入只监听 IPv4/IPv6 回环；开启则让用户选择指定监听地址。TLS 开启后 HTTPS，关闭后 HTTP。明文 HTTP 可用于本机和用户显式开放的局域网；公网远程通过 HTTPS 或可信 TLS 终止代理。用既有原生文件授权导入证书和私钥，验证名称、期限及密钥匹配。启动失败保留旧有效配置，配置关闭或变更会撤销旧连接，并展示当前可用地址。
- 每个客户端单独认证、设置可见工具和资源、订阅/分类范围、是否读正文及写入权限，支持撤销。提供支持手工 Bearer Token 的客户端接入；需要自动 OAuth 发现的远程客户端可通过可信 OAuth 授权服务/代理接入，验证 issuer、audience、有效期和 scope。无身份与越权在执行前拒绝。检查 Host/Origin、限制请求长度、连接及速率，禁用信任任意代理头。资源 URI 与同一应用工具执行相同的数据授权。第三方 AI 默认只看到自己获准的工具；对外出口发布折栈自有工具和资源，导入的外部工具在本机聊天使用。
- 外部写操作仍经应用审批。客户端收到可追踪的审批状态，取消和超时均可追踪，拒绝/撤销不会执行。配置界面显示连接端口和实际协议、测试连接、已授权客户端与执行历史。

## 6. 存储和迁移

新增模型覆盖字段/缓存引用、上下文快照、Skills 版本、工具审批/审计、MCP 配置。密钥、私钥材料不落普通 SQLite。迁移前复用一致快照，固定升级与恢复测试。网络/模型调用在事务外，事务只提交业务状态与审批结果。公共缓存原子替换，已保存偏好、旧历史与旧只读审计可继续显示。整个任务按统一版本验收，SDK、目录刷新、外部访问或各扩展能力可以独立关闭或恢复配置。
