# AI 能力与工具平台

状态：需求调研与详细设计。用户明确同意创建一个总任务。全部需求按一次整体交付验收，实施可逐块联调及本地提交。

## 目标

让折栈 AI 可以按权限操作应用，并通过 MCP 接入第三方工具、向其他 AI 提供应用工具。模型调用采用官方 SDK。用户能理解和管理模型的能力、价格、来源、图标及会话上下文。

## 边界

工具覆盖具备真实应用服务、能定义授权目标并安全返回结果的能力。原始密钥、任意 SQL、任意命令、任意文件读写、任意 URL 请求、修改工具权限以及由工具批准工具调用属于应用控制面。OPML 使用既有用户授权文件流程。模型目录中的价格是标价或参考价，账单以实际服务为准。多模态图标表示模型支持的输入类型，本轮聊天保留现有文字与文章附加入口，上传编辑器另行设计。

## 已确认的部署设置

MCP Server 默认关闭，首次启用时仅允许本机接入。由用户设置端口、是否允许本机外接入以及是否启用 TLS。启用 TLS 后以 HTTPS 提供服务，关闭时以 HTTP 提供服务。允许本机外接入后显示实际监听地址，并要求给外部客户端配置凭据，详见设计。外部连接的授权可以独立撤销。
