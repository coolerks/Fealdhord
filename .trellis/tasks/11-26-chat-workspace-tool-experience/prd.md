# 全局 AI 会话组织与工具体验

## 目标

在会话侧栏直接管理分组，新对话发送前可确认归属，技能在发送后随消息可追溯。全局 AI 能按需加载已配置的 MCP，并按用户设置完成较长的工具链。

## 需求与验收

| 编号 | 可观察行为 | 实施任务 |
| --- | --- | --- |
| R1 | 分组右键可编辑、归档、移除。新建和编辑可设置名称、目录、图标与颜色。归档从侧栏一并隐藏分组和组内会话，恢复后回到组内，单独归档的会话保留归档状态。设置可查看、恢复和删除已归档分组。移除及删除分组均保留磁盘目录和会话，解除会话的分组关联。 | [会话分组](../11-26-chat-group-management/prd.md) |
| R2 | 从分组会话触发全局新对话时继承该组，输入框下显示带图标和关闭按钮的分组条。关闭后首条消息发送为普通会话。普通新对话无分组条。 | [会话分组](../11-26-chat-group-management/prd.md) |
| R3 | 斜杠菜单的各类操作显示与用途匹配的图标，搜索、键盘选择与子菜单返回可用。 | [技能与输入](../11-26-skill-composer-experience/prd.md) |
| R4 | 技能新建、导入预览与编辑可选图标和颜色，保存后在技能列表和聊天选择中显示。旧技能和未配置的技能使用默认图标。 | [技能与输入](../11-26-skill-composer-experience/prd.md) |
| R5 | 发送成功后移除输入框中本次选择的技能，并在对应用户消息开头显示技能标记。重开会话仍显示。排队与引导按当次提交携带技能，发送失败可重试。 | [技能与输入](../11-26-skill-composer-experience/prd.md) |
| R6 | 已配置且允许 AI 使用的 MCP 在连接断开后仍能被发现。模型选定后按需连接，成功后本轮可见相应工具，沿用已有工具授权和审批。连接失败时可见结果。 | [MCP 与预算](../11-26-chat-mcp-tool-budget/prd.md) |
| R7 | 全局聊天每条用户消息触发的运行有两个独立上限，模型轮次默认 200 轮，工具调用默认 300 次，两项均可在设置中调整。先触达的上限生效。达到上限时保留已生成内容，提示触发项、该项实际生效值和设置入口。 | [MCP 与预算](../11-26-chat-mcp-tool-budget/prd.md) |

## 边界与联验

- 分组操作只管理应用记录及目录授权。沿用共享图标与颜色组件、目录选择器和 Wails 绑定。
- MCP 按需加载使用用户保存的连接配置。配置、凭据和现有的单项工具权限由应用管理。MCP 服务端导出接口沿用既有契约。
- 覆盖旧数据库读取、分组与技能重开后的展示、消息归属和技能快照，以及 MCP 加载后在同一轮调用工具。各子任务通过对应的 Go 回归和前端检查，整合后再更新产品交接。

## 现有实现

- 分组只有新建和读取入口，归档界面只管理会话。斜杠入口已有按操作区分的图标参数，但图标组件仍会回退到相同的默认语义。
- 用户选择的技能已可随普通发送请求交给后端。消息记录没有独立的技能字段。
- MCP 聊天工具来自当前内存连接。运行器使用固定 16 个模型轮与 64 次工具调用上限。
