# 执行顺序与验收

1. 评审父任务和三个子任务的 PRD、设计与实施计划。收到明确批准后，从会话分组子任务开始，按 inline 模式在当前主会话完成。
2. [会话分组](../11-26-chat-group-management/implement.md)先落数据库、目录与归档契约，再接侧栏、输入框分组条和设置。通过验证后提交。
3. [技能与输入](../11-26-skill-composer-experience/implement.md)基于步骤 2 的聊天入口写入单条消息技能快照，并完成斜杠图标与技能设置。通过验证后提交。
4. [MCP 与预算](../11-26-chat-mcp-tool-budget/implement.md)基于步骤 3 的每轮技能选择与工具授权接按需连接和两项运行限制。通过验证后提交。
5. 依序运行前端生产构建、`go test ./...` 和 `go vet ./...`，同时完成前端 lint、类型检查和相关单测。检查绑定、迁移及最终差异；如仓库已有故障，复核基线并如实记录。同步中文设计、规格、API、需求追踪、CURRENT 和 LATEST，按完成部分本地提交并核对提交范围。

开始步骤 2 前重新核对当前迁移号、工作区差异和已评审文档。涉及的文件可能与进行中的定时任务会话规划相邻，限定变更为本任务用例。验证以自动回归为主，桌面样式和真实外部连接另记实测范围。
