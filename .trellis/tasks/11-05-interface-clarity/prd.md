# 界面减负与三方体验一致性

## 目标与授权

将用户要求的两条规则原文加入 AGENTS.md，并修正当前界面中的违规内容。用户已确认创建任务并继续，沿用按完成部分本地提交授权。本任务不改变数据服务、领域模型或已实现功能。

## 当前证据与范围

Sidebar 的品牌副标与底部标语、Toolbar 的视图解释、Shell 的空态宣传语／重复模式标签／常驻快捷键、SettingsDialog 的宣传与开发阶段说明、Reader 的宣传性占位均冗余。Sidebar 标为“搜索”的按钮实际打开命令面板，语义不一致。

## 实现与验收

- 加入用户两条规则；保留现有禁止子代理和 inline 配置。
- 去除冗余文案，标题、按钮及选中态直接表达功能；保存／错误／实际加载范围等必要反馈保留。
- 整合重复工具栏；空态提取成独立组件，避免 Shell 内多层嵌套判断，删除对应死 CSS。
- 操作名称与行为一致，保留无障碍名称、表单 label、角色、菜单和焦点路径；复用现有命令，不另起行为分支。
- 更新已有测试断言及必要的语义／回归用例，运行前端类型、lint、测试及构建；同步中文规范和交接，直接提交。

用户体验以更少重复内容及明确动作改善；开发体验以组件边界和样式清理改善；AI Agent 体验以稳定准确的语义操作和统一命令改善。不增加 E2E，不扩展 RSS／AI 未实现功能。
