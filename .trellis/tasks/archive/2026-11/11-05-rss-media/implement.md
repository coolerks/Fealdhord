# 首图候选与受控媒体加载执行顺序

状态：已按批准范围实现并检查通过（2026-11-05）；实际证据见 docs/09-research/phase3-validation.md。

1. 复核依赖：ingestion 网关和 refresh 提交后钩子均完成后；读取父设计、当前 PRD 和目标层编码规范。
2. 先迁移与隐私默认值兼容测试；实现候选与尺寸探测、有限回退、缓存／handler；恶意媒体和禁图测试后提交。
3. 按父任务[门禁](../11-05-phase3-rss/implement.md)运行本职责相关检查，更新 CURRENT／交接与 API／Schema 契约。
4. 每完成职责清晰的一部分直接本地提交，验收后归档并继续后续已批子任务。

不默认 E2E；需要真实运行时只验证无法由集成测试替代的关键路径，不进行视觉调整。
