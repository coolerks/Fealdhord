# 首图候选与受控媒体加载技术边界

详细契约见[统一方案](../11-05-phase3-rss/design.md)，本文件只界定子任务责任。

修改范围：internal/media、媒体迁移／设置、main 的本地 handler。执行前置：ingestion 网关和 refresh 提交后钩子均完成后。共享 DTO／安全策略／事务所有权由父设计约束，禁止复制绕过网关的抓取器或让生成代码成为手改入口。

边界：候选优先级和相对 URL；禁图零媒体请求；失败不阻塞文章；有界图片、LRU／TTL 和仅已登记媒体 ID 加载。数据／API／设置变化同步实际规格；与其他子任务交换明确类型或提交后钩子，不引入循环依赖。独立提交为回退点，已有生产数据和状态必须保留。
