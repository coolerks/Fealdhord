# 自定义权限

## 目标

用户可按工具决定调用时是否确认，适用于内置工具和折栈连接的外部 MCP 工具。

## 现状

全局聊天输入框和新会话默认设置共用三种审批模式。内置工具注册时声明是否需要审批，外部 MCP 函数工具默认需要审批。设置中的 MCP 服务端授权另行管理外部调用方的访问范围。

## 需求与验收

1. 全局聊天输入框的审批下拉新增第四项「自定义权限」，并在「设置 → 服务与模型 → 工具审批 → 默认审批方式」提供同一选项。保存默认后，新对话自动选中该模式。当前会话手动选择的模式优先于全局默认。输入框的审批按钮显示模式文字，图标在下拉选项中显示。
2. 在「设置 → MCP 与权限」提供逐工具配置。工具可搜索，展示内置工具、外部工具与所属连接。每项支持「默认」「需要审批」「拒绝」「放行」。默认沿用该工具原有的审批要求。保存后可重新打开设置查看，重启后仍有效。
3. 选择「自定义权限」时按规则执行。「需要审批」进入已有确认流程。「拒绝」阻止调用且不弹确认。「放行」让符合既有授权的调用直接执行。切到其他会话模式时按该模式原有规则执行。验收使用同一个工具切换模式并核对实际调用次数。
4. 不同连接上的同名工具可分别设置。连接暂时断开后重连，原规则仍可用。更换连接目标后按新目标的默认规则执行。
5. 对显式授权的正文工具，逐工具规则同样可生效，正文读取仍限当轮获准的文章。技能白名单、原有参数校验、外部 MCP 服务端客户端授权和审计继续生效。验收覆盖通过普通工具目录和精简目录调用时均执行同样的规则。

## 范围

此次覆盖折栈全局聊天发起的工具调用和桌面设置。外部客户端调用折栈 MCP 服务时继续使用该客户端的独立授权和审批规则。外部 MCP 资源读取与提示词获取按聊天中实际提供的工具配置。逐工具规则为应用级设置，会话切换选择适用的审批模式。
