# MCP 按需连接与工具调用预算设计

## 连接与动态工具

模型拿到已配置、可供聊天使用的 MCP 摘要，按稳定 ID 调用加载工具。摘要使用服务名称及已有的安全发现元数据帮助选择，边界内处理为数据。加载从本地读取已保存的配置和凭据，去重并复用连接，与手动断开或忘记串行化。自动或意外断开后允许重新加载。主动断开表示暂停模型重新连接，手动连接后恢复，忘记后从目录移除。未保存的目标、模型提供的端点／命令／密钥不进入加载契约。

工具集使用 `agentrun.StreamOptions.RefreshTools` 在加载成功后的模型轮刷新，同时结合现有计划确认切换。保持本轮技能允许范围、用户工具开关和运行时授权。外部工具继续使用现有审批，连接失败返回简洁的状态和诊断信息。外部调用结果不确定时保留现有处理，下一次连接不自动重放调用。导出的 MCP 服务接口照常工作。

## 两项预算

使用全局聊天偏好提供默认 200 个模型轮和 300 次工具调用。设置分别使用带名称的整数输入，取有效正整数，保存值从下一次运行读取。运行时快照贯穿本轮及错误展示。模型轮包含最终回答，工具预算按工具执行计数，同一调用的协议重发不重复执行。达到配置边界时，允许预算内的最终回答。模型仍要求超额工具或新模型轮时，保存部分输出，返回结构化的限制类型和该项生效值。将运行结束原因与聊天提示关联至对应设置。保持其他超时、压缩、分页、取消和重试限制，各类错误使用自身语义。
