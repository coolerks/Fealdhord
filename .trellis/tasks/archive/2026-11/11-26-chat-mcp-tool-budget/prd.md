# MCP 按需连接与工具调用预算

覆盖父任务 R6、R7。

- 当前 `internal/appagent/client.go` 的聊天工具仅来自内存连接。为符合现有授权的已保存 MCP 提供模型可读的目录和按需加载入口。加载按应用分配的稳定 ID 选择连接，复用会话以及保存的配置和凭据。已连接服务可复用，主动断开／忘记与意外断连的语义需要在设计中落实。
- 新加载的工具对本次运行后续模型轮可见，沿用用户权限、计划模式和禁用工具的限制；不将凭据或连接参数返回模型。加载错误可区分连接失败和权限不足。
- 当前 `internal/agentrun/stream.go` 同时限制 16 个模型轮与 64 次工具调用。全局 Chat 改为两个独立设置，默认 200 个模型轮（含最终回答轮）与 300 次工具调用。新值从下一轮用户消息生效，先触达的上限生效。每个模型轮可提出多个工具调用，逐轮只调用一次的链路会先触达模型轮次上限。保留现有取消、超时、有限重试等保护。
- 验收涵盖意外断线后加载、同一轮加载并调用、拒绝未授权服务、避免自动重放失败的外部调用，以及两项默认值和设置持久化。用批量工具调用和逐轮调用分别触发两项上限，核对错误提示里的限制类型、实际设置值及设置入口。
