# MCP 按需连接与工具调用预算实施

1. 前置依赖是分组、技能与输入两阶段已提交。核对权限来源与工具刷新路径，复用连接和凭据解析，加入稳定 ID 目录及加载工具，验证断开和重连策略。
2. 合并工具刷新与计划切换，覆盖已禁用、未授权、手动断开、并发加载、外部调用不重放，以及加载后同轮能调用。使用本地测试 MCP 和模型，连接日志不泄露凭据。
3. 增加两项设置、运行器预算快照、结构化终止信息和设置提示。验证默认、持久化、逐轮与批量边界、回复保留、两项限额独立以及设置变更只影响下一轮。
4. 跑 `go test ./internal/agentrun ./internal/appagent ./internal/chat ./internal/settings`，再跑 MCP 连接与权限的相关竞态检查、前端类型／lint 及设置测试。更新权限、API 和状态文档后提交，进入父任务集成验收。
