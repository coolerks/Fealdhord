# Phase 4 技术设计

## 1. 边界

Go 拥有 SQLite、网络、安全 HTML、系统浏览器和文件授权；生成绑定只暴露白名单 DTO。TanStack Query 管领域缓存，Zustand 仅管 UI／偏好／短期进度。沿用现有功能布局、图标动效、状态写入和受控网关。

## 2. 查询

新增 LibraryService.Query(ArticleQuery)，保留 List 兼容已交付调用。默认 50／上限 200，scope／search／read／favorite／sort 均入前端 Query 键。时间查询按 sort_at／id 键集，首请求记录 rowid 上界防止后来插入混页；全文排序额外记录 rank 与索引 generation。游标带查询摘要、有效期及签名，非法／过期返回 CursorExpired，不忽略错误。

新增增量迁移记录 FTS generation，文章索引变化及重建使全文游标失效。全文沿用受测编译器与中文连续性复核；单次扫描有界，若候选达到上限返回可继续的游标及提示，不谎报搜索已穷尽。摘要保持纯文本，命中范围不注入原始 HTML。前端分页数组只在 Query 保存，命令／状态写入共同迁移，保留失败回滚和导航锚点。

## 3. 分类与导航

沿用 effective_article_categories 统一来源优先级。分类 CAS 更新、树深最多 5、同父级唯一、删除子项迁移原子化；preview 显示影响且不写入。单独导航 DTO 返回树、订阅和全库计数；scope 独立保存 ID，不能把当前已加载页当全库计数。人工成员独立 included／excluded／auto，Feed 继承不覆盖墓碑。

## 4. 阅读

订阅 HTML 二次安全清理并限制所有可加载资源；远端链接只通过 Go 校验并调用系统浏览器。Reader 提取使用固定版本后继 Readability，仅解析网关抓取的有界字节；不调用库联网入口。结果写 reader_contents，订阅正文保留独立。显式 operation 取消，提交前核对内容版本；失败保留已读内容。自动已读只在正文实际成功呈现后发生，复用幂等 SetRead 和失败回滚。

## 5. OPML

原生对话框在 Go 授予一次性、带用途／到期的能力，不接受前端路径。预览只读受限文件，保留合法 Folder 与 Feed 关系；确认事务内复核 revision／冲突，导入不隐式无限抓取。导出先完整构造／写同目录临时文件，再安全替换授权目标；取消或失败保留原文件。

## 6. 兼容与回退

新增迁移，不修改 00001–00005；升级一致快照。新增偏好有安全默认，保留旧正文／状态／别名。各部分提交为回退点，不能用破坏性 Down 恢复用户库。后续范围有实质变化时更新本方案；不自行启动未获授权的 AI 阶段。

## 7. 验证

真实 SQLite 分页／FTS／多来源／CAS，组件旧响应／分页／操作回滚，受控网络／安全 HTML fixture、OPML 限额／事务／文件失败；必要 race、格式／类型／lint、绑定及原生构建。非必要不做 E2E，不访问用户生产库。
