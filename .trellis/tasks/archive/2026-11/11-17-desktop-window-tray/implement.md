# 实施与验证

1. 评审需求、方案与验收项，激活任务并读取桌面 Go 和前端规范。
2. 接入 SettingsService、前端设置分段控件和生成绑定。装配三端关闭拦截和窗口恢复。核对显式退出、首次显示、启动器重入与恢复原窗口的调用路径。
3. 生成 Windows 专用图标，调整本地与发布资源生成。检查 ICO 多尺寸、主体占比和 Windows x64 程序资源。
4. 覆盖旧设置缺字段、两种选择的持久化及更新顺序。执行 Go test、Go vet、前端类型与 lint 检查、macOS 构建和 Windows x64 交叉编译。Linux 原生构建依赖 GTK 与 WebKitGTK，记录能实际执行的检查。
5. 在可用平台做最小原生验证，覆盖后台留存、恢复、选择「退出应用」后点击叉号，以及两种设置下的显式退出。记录实机环境缺口。
6. 同步 Wails 绑定契约、原生体验规格、CURRENT、LATEST 和 Trellis 任务，按授权提交本轮文件。

回滚边界为关闭偏好、桌面装配、平台图标生成及其提交的 Windows 资源。旧偏好 JSON 无需迁移。

## 验证记录

- Go 全包测试和 vet 通过，覆盖旧 SQLite 偏好读取、写入冲突和保存通知。前端 121 项测试、类型检查、lint 和生产构建通过，保留已有 Virtualizer 与构建分块提示。
- macOS arm64 构建及调试包签名通过。隔离数据的 AppKit 探针验证关闭隐藏、恢复同一窗口、保存退出偏好后再次关闭触发清理。界面自动化连接异常，Dock 和状态栏实际点击待验证。
- Windows x64 交叉编译通过。ICO 包含 16、20、24、32、40、48、64、128、256 像素资源，图稿主体相对旧版放大约 12%。Windows 实机待验证。
- 本机缺少 GTK 与 WebKitGTK 的 Linux 构建环境，Linux 编译和实机待验证。
