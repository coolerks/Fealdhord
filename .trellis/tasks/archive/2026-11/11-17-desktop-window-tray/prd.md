# 三端关闭后后台驻留与 Windows 图标修复

## 目标

关闭折栈主窗口后保留后台刷新和当前阅读状态，从系统图标快速回到原窗口。提高 Windows 上折栈图标的可读性。

## 需求与验收

| 编号 | 需求 | 可观察的验收结果 |
| --- | --- | --- |
| W1 | Windows 任务栏放大图标主体，托盘使用原应用的彩色图案 | 任务栏白色底板和折页的占比高于现版；Windows 托盘可辨认彩色折页；macOS 状态栏仍由系统着色 |
| W2 | 三端关闭主窗口后继续运行 | 点击叉号后原进程继续运行；Windows 和 Linux 的窗口从任务栏移除；macOS Dock 保留应用，运行圆点遵循系统设置 |
| W3 | 从系统入口恢复原窗口 | 三端单击托盘或状态栏图标即显示并激活原窗口。macOS 点击 Dock 恢复。Linux 从支持 StatusNotifierItem 的托盘或应用启动器恢复。阅读位置与窗口状态保留 |
| W4 | 保留显式退出 | 托盘菜单「退出折栈」及现有应用退出入口仍结束进程并执行清理 |
| W5 | 在设置中选择点击叉号的行为 | 「关闭窗口时」可选「在后台运行」或「退出应用」。新安装和未保存此偏好的旧版本用户默认在后台运行。保存成功后立即生效，重启后保留 |

本次修复覆盖当前桌面版本和已有的打包入口。Linux 图标入口由桌面环境提供，托盘验收在支持 StatusNotifierItem 的环境中执行。
