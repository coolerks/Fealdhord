# 实现与验证

1. 评审通过后启动任务，加载前端规范和 shadcn/ui 现有样式配置。
2. 修整 SearchableSelect 及使用方，覆盖 9／10 项、长标签、短选项、禁用项、单选与多选、键盘和滚动。核对短名单与长模型名单的实际弹层几何。
3. 复用阅读侧栏组件与动效，接入新对话快捷键，并验证当前模式、弹窗和忙碌态限制。测试真实 AnimatedGlyph 从悬停或聚焦获得中间帧。
4. 接入阅读与 AI 双向过渡，检查两栏在两个方向有中间动画态、减少动态与关闭、离场不可交互、快速切换、焦点和原阅读位置。使用最小必要的布局和动画可视验证。
5. 执行相关前端测试、lint 与生产构建，按实际证据维护产品规格、当前状态和交接，再按阶段提交并归档。

## 验证记录

- 前端 141 项测试通过，覆盖新对话快捷键、两栏双向过渡中间帧、会话图标动画、离场不可交互、阅读位置与焦点恢复，以及既有的下拉搜索、选择和关闭。
- Chrome 使用本机回环探针验证短列表、超长标签和 28 项长列表。列表的滚动宽度均等于可用宽度，勾选可见；只有 28 项列表出现纵向溢出。探针已移除，服务已关闭。
- lint、类型检查和生产构建通过。桌面原生视觉待验证。
