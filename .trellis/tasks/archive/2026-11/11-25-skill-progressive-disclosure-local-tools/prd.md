# Skill 渐进式披露、会话分组与本地工具

## 目标

让折栈安装和使用带说明、参考资料、脚本及二进制资源的 Skill，模型按需获取文件内容。全局 AI 侧栏支持会话分组，分组关联的目录作为会话的工作目录。会话提供 `read`、`write`、`edit` 和 `shell`，文件列表、搜索和其他命令交给 `shell`。

## 背景

- [导入器](../../../internal/appagent/skill_import.go#L15) 将 256 KiB 的说明文件上限与 12 KiB 的资源上限相加，得到 268 KiB 的 ZIP 上限。参考资料只接受指定目录中的 Markdown、TXT、JSON。用户截图触发了 ZIP 文件上限。
- [Skill 运行入口](../../../internal/appagent/skills.go#L125) 在用户选择 Skill 后把说明和所有参考资料一起附到模型提示中。设置预览和保存也承载完整参考文本。
- [工具运行时](../../../internal/agentrun/stream.go#L17) 和[通用结果分页](../../../internal/agentrun/result_pages.go#L20) 有 12 KiB 上限。需要给这组工具处理自己的分页结果，避免合法的 `read` 返回被通用上限吞掉。
- [AI 侧栏](../../../frontend/src/features/chat/ChatDialog.tsx#L452) 只有一个会话列表。[建立会话](../../../internal/chat/service.go#L148) 和[构造首轮请求](../../../internal/chat/service.go#L343) 当前均没有分组目录。草稿发送首条消息时才创建会话，这个时机保留。
- Agent Skills 客户端指南给出元数据、说明、资源三级加载方式。Pi 给出 `read` 的起始行、行数和 2,000 行／50 KiB 限制。OpenCode 的 `write` 自动建父目录，`edit` 默认唯一精确匹配，支持显式 `replaceAll`。参考链接见文末。

## 需求

### S1 安装与兼容性

- 保留单个 `SKILL.md` 导入、预览、保存、编辑、启停和删除入口。ZIP 支持声明文件位于根目录或一个顶层 Skill 目录，保留包内常规文件的相对路径和字节内容。安装操作只存储文件。
- 包内文件放在独立的受管目录。预览只包含说明和文件清单。压缩大小、解压大小、文件数和文件层级使用独立的导入限额，超限时显示触发的具体限制。替换现有 268 KiB ZIP 和 12 KiB 参考文本总量限制。
- 预览取消、导入失败或同名包更新失败时，保留现有版本。继续读取旧 JSON 保存的 Skill，迁移保留启停、说明、工具声明和资源内容。校验路径穿越、符号链接、特殊文件、重复和目标平台的大小写冲突。

### S2 渐进式披露

- 会话初始只提供启用 Skill 的名称、描述和可用于读取的入口。模型根据任务读取相关 `SKILL.md`，用户手动选择的 Skill 也进入同一加载流程。
- 只有实际请求资源时才向模型返回该文件的选定文本范围。读取说明或资源不增加工具授权。让模型在使用自带文件时能够解析 Skill 内的相对路径。
- 包内脚本随包保存。任何脚本只经显式的 `shell` 工具调用及其授权执行。

### G1 会话分组与侧栏

- 全局 AI 侧栏在「会话」上方新增「分组」，从「新建分组」打开标题为「新建会话分组」的对话框。填写分组名后可添加零个、一个或多个本地文件夹。原生选择器可重复添加，保存前可移除某项。分组及文件夹选择一并保存。
- 每个分组提供组内新对话入口。普通「新对话」和快捷键继续建立普通会话。组内分支继承分组，归档与恢复保留关联，已有会话继续列在普通「会话」区。
- 「分组」区、「会话」区和各个分组项均可独立展开与收起。折叠只改变侧栏可见内容，当前打开的会话和生成状态照常维持。分组可以没有目录，也可以暂时没有会话。

### G2 目录上下文与按需创建

- 每轮全局会话的系统提示词列出当前分组保存的绝对路径。文件工具可在已授权的分组目录内操作，路径顺序用于确定默认工作目录。其他分组的路径不进入本轮请求。
- 普通会话和没有目录的分组使用 `~/.Fealdhord/会话文件/YYYY-MM-DD/会话ID`，将默认输出集中在主目录下的点目录。日期取设备本地时区的会话创建日并固定。系统提示词明确要求在有新文件写入需求时使用该目录，由 AI 调用写入工具按需创建目录。
- 新建分组、打开空草稿、建立会话和发送纯文本时均不创建普通会话目录。只读和目录检查也不创建目录。默认目录授权只覆盖当前会话子目录。

### T1 `read`

- 输入为 `path`、可选 `offset` 和 `limit`。从第 1 行开始计数，返回带原始行号的内容，以及截断状态和下一读取位置。单次最多 2,000 行且工具返回不超过 50 KiB，两者取先达到的一项。
- 根据文件字节识别文本或二进制，识别为二进制时返回跳过状态，避免向模型发送二进制内容。无后缀的文本可读，伪装成文本扩展名的二进制仍跳过。流式读取并确保超长行和多字节字符不会让续读停在同一位置。

### T2 `write` 与 T3 `edit`

- `write(path, content)` 创建或完整覆盖文本文件，自动创建缺失的父目录。失败时保留既有文件内容。
- `edit(path, oldText, newText, replaceAll=false)` 按字面文本替换。默认仅在恰好一处匹配时写入，未命中或存在歧义时保留原文件。显式设置 `replaceAll=true` 时替换所有非重叠匹配并返回替换数。拒绝空旧文本和对二进制执行文本替换。

### T4 `shell`

- 输入为命令及可选工作目录和超时，返回退出状态、标准输出、标准错误和截断状态。支持取消及超时，覆盖派生子进程。目录枚举和文本搜索使用 shell 命令。
- 首期工具只服务本机聊天。文件工具按当前分组或普通会话目录授权访问，同时可读取当前会话可用的 Skill 路径。安装的 Skill 目录只通过文件工具读取。
- 每次执行复用折栈单次工具审批。界面展示完整原始命令和实际工作目录。用户批准后，进程以当前桌面用户身份运行，可使用该用户已有的系统权限。`workdir` 只决定进程的起始目录。会话拒绝模式和自定义拒绝照常生效。每条命令需要取得本次批准。

## 验收标准

- [ ] 成功导入超过 268 KiB 且同时包含长参考文档、脚本和二进制资源的 ZIP，重启后可读。安装和打开预览均没有执行脚本。恶意路径及超限 ZIP 被拒绝，更新失败保留旧版本。
- [ ] 模拟模型验证首轮只有 Skill 元数据，激活后出现说明，读取指定参考资料后才出现其内容。未读取的资源没有进入模型请求。手动选择、启停、旧 Skill 及既有权限仍可用。
- [ ] 可以创建零、一或多个目录的分组。重启后分组、目录和会话归属可恢复。侧栏三个折叠层级相互独立。普通新对话、组内新对话、分支、归档和恢复的归属符合预期。
- [ ] 模拟模型验证只收到当前分组目录。普通会话和空分组收到默认目录及创建指引。新建、首轮纯文本、跨天发送和重启均不会提前创建或改变目录。首次成功写入可创建父目录，并拒绝跨会话或跨分组访问。
- [ ] `read` 对无后缀文本、伪装扩展名、二进制、中文、多页、CRLF 和超长行正确处理，返回真实行号，并严格遵守两个限制。读取结果经过真实的聊天工具链，没有被现有 12 KiB 限制错误截断。
- [ ] `write` 创建多级父目录并能覆盖文件；`edit` 正确处理零、一、多处匹配和 `replaceAll`。并发修改、访问越界和中断测试覆盖数据完整性。
- [ ] `shell` 能执行目录列表、文件搜索和用户授权的脚本。弹窗和输入框内审批均显示完整命令和实际目录。单次批准使用所展示的命令和目录执行一次，拒绝、审批过期或取消时不启动进程。测试覆盖非零退出、输出截断、超时和子进程回收。
- [ ] 外部 MCP 无法调用这四个本地工具。Skill 文件内容无法扩大工具权限。文件工具针对已授权根目录校验，进程权限符合已批准的主机执行方式。
