# 实施计划

## 开工前

- 用户评审最新规划摘要后启动任务。加载后端目录、权限、错误和日志规范，前端组件、Hook、类型及质量规范。
- 记录基线。确认当前分支、工作区和绑定生成方式，保留现有修改。四个验收阶段在同一任务内推进，各阶段验证通过后按项目要求提交。

## 1. 会话分组与目录上下文

- 添加 SQLite 迁移、生成查询及会话分组绑定。验证存量会话归属、日期回填、组内分支和归档恢复。用真实临时 SQLite 验证持久化与顺序。
- 接入全局 AI 侧栏分组、原生目录选择和组内新对话。覆盖「新建会话分组」对话框、空组、多目录、取消选择和三个独立折叠层级。保留原有普通会话列表、快捷键、后台回复及键盘导航。
- 统一生成系统提示词和工具目录范围。模拟模型捕获实际请求，验证当前分组全部路径、其他分组隔离及普通会话和空分组的 `~/.Fealdhord/会话文件/YYYY-MM-DD/会话ID`。在创建、跨天重开、纯文本首轮和只读测试中检查文件系统，确认目录未提前创建。

## 2. 安装与设置

- 在 `internal/appagent` 拆开解析、暂存和发布。实现独立包限额、归档路径和平台冲突校验、一次性预览、提交、取消与故障清理。
- 建立只返回元数据的 Skill 列表及按需详情。接入旧 JSON 读取和迁移，对编辑、启停、删除和同名导入增加版本保护。先保留现有模型加载入口，下一阶段切换到目录式读取。
- 更新桌面绑定和 Skills 设置。预览展示声明、相对路径和大小；错误显示实际触发的限制。加载列表与预览时检查二进制正文、脚本正文和参考文本未通过绑定传输。
- 测试大于原 ZIP 上限的真实字节大小和压缩包结构、BOM、CRLF、带脚本与二进制资源、路径异常、重复冲突、解压限额、取消、升级迁移、失败和重启后的版本选择。

## 3. 渐进式披露与 `read`

- 实现 Skill 虚拟路径和文本分页读取，复用阶段 1 的会话目录授权。文本分页自己处理 2,000 行、50 KiB、二进制、字符边界和行内续读。
- 更新 `Platform.RunTools`、`internal/chat` 和 `internal/agentrun`。初始请求只给元数据，按读取逐步激活，继续执行工具白名单与独立目录授权。审查工具结果分页、目录压缩、上下文预算和重试边界。
- 用模拟模型逐轮验证目录、声明、指定资源及真正的读文件结果，确认未打开的资料不会出现在请求中。覆盖手动选择、停用、工具关闭、上下文压缩、目录压缩、错误路径和原有业务工具。

## 4. `write`、`edit`、`shell` 与审批

- 对本地文件操作落实受限根、原子写入和并发修改检查。验证普通会话首次写入补齐父目录、默认根未建立时的命令起点，以及相邻会话与其他分组隔离。
- 接入 `shell` 的参数校验和单次批准策略。沿用现有待审批对象和桌面交互，把完整命令和实际目录加入两种审批显示，并覆盖滚动、键盘和未批准前无副作用。
- 实现本机进程管理、输出截断、非零退出、超时和取消。保护进程环境、审计输出和 MCP 暴露边界。
- 验证批准执行一次、重复批准无副作用、绕过模式仍确认、拒绝与取消、主机工作目录一致，以及工作目录越界失败。用无副作用命令验证目录枚举、搜索、脚本和普通子进程回收。

## 验证与记录

- Go 定向测试使用 `go test ./internal/appagent ./internal/agentrun ./internal/chat`。运行相关包竞态测试、`go test ./...` 和 `go vet ./...`。
- 运行 `task bindings` 后验证生成文件和调用方。前端运行 `task frontend:check` 与生产构建，侧重侧栏分组和目录选择、Skills 预览及两种审批界面。只在平台进程或原生选择器行为无法用集成测试验证时运行最小桌面验收。
- macOS、Linux、Windows 分别验证命令执行、路径和取消。无实机的平台记录交叉编译证据与剩余验证。切换 Skill 版本及写入覆盖重点检查 Windows 文件替换行为。
- 初期同时兼容旧 JSON 和新目录，旧记录保留到迁移和回滚操作验证完成。每个阶段在对应产品规格、API 契约和后端规范记录实际落地行为。交付时更新 `CURRENT.md`、`LATEST.md` 和修改记录。
