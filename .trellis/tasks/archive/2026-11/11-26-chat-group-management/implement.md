# 会话分组管理实施

1. 在主会话读取前后端规范。变更分组迁移与 SQL 查询，补齐事务及归档、恢复、删除 API，运行 `sqlc generate` 和 `wails3 task bindings`。
2. 接入共享图标选择和对话框、侧栏上下文菜单、新对话归属条和归档设置，按最小范围同步缓存及路由。保持前一轮侧栏整行交互。
3. 在临时目录与数据库验证归档恢复、已有会话独立归档、外键解绑、目录保留与权限刷新。用组件测试覆盖右键、归档设置、组内新对话进入及取消分组。运行 `go test ./internal/chat ./internal/database` 和前端相关测试、类型及 lint 检查。
4. 核对迁移与绑定、同步分组契约和状态，提交该阶段。下一阶段在现有归属逻辑上接入技能消息。
