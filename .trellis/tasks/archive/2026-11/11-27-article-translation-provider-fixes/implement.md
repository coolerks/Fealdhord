# 实施顺序

1. 修复阿里云响应解析、凭据保存与草稿来源验证和摘要完成判定。覆盖官方数字响应、无效或跨来源地址、配置保存失败、部分摘要及旧缓存恢复。
2. 修复正文分片、标记校验和取消清除的交互。覆盖重启续译、代码与链接还原、无效标记、延迟返回与清除。重点核对 `body_api.go` 与现有 AI 正文共享的检查点和缓存行为。
3. 修复百度补译限流、后台队列和阅读器设置入口。测试原请求与补译使用同一限流等待、文章级延后，以及 AI 与机器翻译错误的按钮和跳转。
4. 同步阅读器规格、绑定契约、CURRENT 与交接。查看工作区差异，只提交本任务文件。

## 验证

- 用临时 SQLite、内存密钥库和模拟 HTTP 响应运行 Go 回归。执行 `gofmt`、`go test -race ./internal/translation ./internal/articleai ./internal/database` 和 `go vet ./...`。涉及本地模拟模型监听的测试使用回环地址。
- 前端运行 `npm run typecheck`、`npm run lint`、阅读器与文章 AI 设置组件测试以及 `npm run build`。
- 通过 `git diff --check` 和按文件审查，确认已覆盖八项验收。记录模拟测试、现有失败及实机未验范围。
