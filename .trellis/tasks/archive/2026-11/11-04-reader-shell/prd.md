# Phase 1：正式阅读 Shell 与双视图

## 目标与已确认事实

用户要求建立下一阶段任务并直接开发直到完成；采用已经展示并批准的 Phase 1 规格，无新增产品范围。现有 Phase 0 工程、绑定与构建已通过；文档中文、禁止子代理、非必要不做 E2E、按完成部分直接提交。

## 需求

- SHELL-01：正式三栏及窄窗口布局，可折叠玻璃侧栏、系统视图／分类／订阅区域、Reader 占位，支持分栏调整。
- VIEWS-01：列表／瀑布流是真实布局，共用数据、选择、筛选和锚点；支持紧凑／舒适、缩略图／原比例图，无图回退。
- DS-01：Light／Dark／System，语义 token 与主题即时跟随。
- MOTION-01：导航、收藏、已读、搜索、布局切换、面板、菜单等语义反馈，支持 Full／Subtle／Off 及系统减少动态。
- PREF-01：通过 Go SettingsService 在 SQLite 保存布局与偏好，重启恢复；非法旧值回退，不把领域数据存 Zustand。
- INPUT-01：键盘导航与焦点恢复，分隔条可键盘调整，设置、搜索和 Command Palette 可用。

## 验收

AC-S01：必要 Go／前端单元与组件测试、typecheck／lint／build 通过。
AC-S02：组件 fixture 验证两个真实虚拟布局、无图／坏图、选择与锚点、宽度变化；生产空库无假文章。
AC-S03：设置持久化、版本冲突、并发更新、错误处理与重开恢复有真实 SQLite 测试。
AC-S04：主题与 Reduced Motion、键盘、分隔条、空态与待交付功能解释清晰。
AC-S05：代码／中文文档／任务状态一致，按完成部分提交；不默认新增 E2E。

## 范围外

RSS 抓取、文章／分类持久化、首图网络提取、AI／MCP 不在本阶段。数据接口当前返回真实空集合；测试 fixture 仅在测试文件使用。设置表是恢复体验所需的最小提前基础，不代表 Phase 2 完成。
