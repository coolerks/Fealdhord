# 技能外观与聊天输入设计

## 技能外观

技能元数据保存图标和颜色，沿用技能包的版本化落盘流程，与 `SKILL.md` 内容和导入包资源分开。复用应用图标及 RGBA 校验。ZIP 和 Markdown 导入都在现有预览确认时保存外观。切换技能启用状态、重开设置或更新技能正文时保留外观。未配置使用默认图标。斜杠菜单的命令图标显式映射至正确语义，技能项使用共享自定义图标渲染。

## 技能随消息提交

每次发送捕获当时的技能 ID 集合。后端沿用启用状态、数量和工具授权校验，保存已选技能的名称及外观快照到用户消息元数据，并在正文及附件之前渲染。快照使旧消息不受后来修改或删除技能影响。应用到模型上下文的技能内容和消息展示元数据各走现有业务边界。消息分支、重开和旧数据库兼容纳入验证。

队列条目拥有提交时的技能集合，独立于下一条草稿。转引导后按同一集合校验，随着引导进入运行上下文，在「中途引导」正文前显示技能。允许的技能借助已有目录与读取流程生效，传入技能不得扩张工具权限。正常发送接受、排队入列及引导接受时清除对应输入中的选择。失败时可重试，并且异步回调不能覆盖用户已开始的新草稿。
