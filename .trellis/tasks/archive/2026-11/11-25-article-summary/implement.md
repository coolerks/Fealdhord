# 文章摘要实施计划

1. 规划评审后读取前后端规范与生成工具约定，然后启动任务。核对当前工作区和迁移序号。
2. 实现 SQLite 迁移及查询，接入默认关闭的自动摘要设置、可独立调整的中英文阈值、版本化结果和文章删除约束。覆盖旧库升级、设置重启读回、阈值变更后按需重判和过期内容隔离。
3. 接入正文来源选择、保守的短文判断、现有摘要模型分配与客户端。实现分批覆盖、结构校验、并发去重、提交时版本校验。在模拟网关覆盖后段信息、有效跳过、失败与重试、迟到响应。用中英文和正文不完整样例校验判断边界。
4. 注册桌面服务并生成绑定，接入文章 AI 设置与阅读器触发、折叠和状态反馈。组件测试覆盖默认关闭、阈值输入与持久化接口、缓存命中、正文就绪、手动失败、切换文章和键盘操作。
5. 同步阅读器规格、跨层 API 与数据说明、需求追踪、当前状态及交接，逐项记录实际验证。通过相关检查后按可独立说明的阶段本地提交。

## 计划验证

- 运行 SQLite 升级与持久化测试、摘要服务及阅读器相关 Go 测试，针对合并与过期写入运行竞态检查，再运行 `go test ./...` 和 `go vet ./...`。
- 运行 `sqlc generate` 和 `task bindings` 后检查生成差异。在 `frontend` 运行 `npm run typecheck`、`npm run lint`、`npm test` 和 `npm run build`。
- 组合短公告、信息密集通知、短 RSS 摘录加长正文、多批长文、重复生成及离线重开样例，检查状态、模型次数与 SQLite 结果。实机或真实模型如果未运行，标记待验证。
