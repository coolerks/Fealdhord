# 实施与验收

1. 兼容读取现有连接、凭据和工具权限。实现稳定连接标识与 Unicode 显示名称，处理保存、重连、改名及移除，测试旧连接保持身份与认证。
2. 接入 STDIO 和 Streamable HTTP 配置、环境引用、连接和调用超时、日志等级、代理、TLS 与重试。以本地进程及模拟 HTTP/MCP 测试各字段，覆盖无代理、代理认证、证书校验开关、缺失环境变量、失败回滚和工具调用不重放。
3. 补齐跨页工具发现与目录可用性验证。使用超过 32 项的多页服务，检查设置统计、后续工具可搜索、权限可保存和实际调用。
4. 接入 STDIO stderr 和 MCP 日志采集、按连接与启动尝试查询的会话内缓冲区。用测试子进程验证实时写入、失败退出、断开后回看、有界读取和脱敏。
5. 生成 Wails 绑定，重做连接编辑器，并为 STDIO 加入日志查看器。使用现有 shadcn/ui 控件和可搜索选择器。验证基础与高级字段、传输切换、旧值回显、启动失败查看日志、关闭查看器停止更新及键盘路径。
6. 运行 Go 相关包测试、竞态及 vet，前端类型、lint、测试与生产构建。同步接口、配置手册、CURRENT 和交接记录，按项目约定逐阶段提交。

## 验收

- 本地多页 MCP 服务验证 47 项工具、旧连接使用中文改名、旧权限键和 Bearer 凭据仍适用，并调用目录最后一项。
- 本地 TLS 与认证代理验证请求头变量、证书默认验证、暂时连接失败重试、工具调用超时且无重放。
- 测试子进程验证环境变量、工作目录、启动时限、stderr 和旧版 MCP 协议日志、失败尝试隔离、脱敏与容量限制。前端测试从连接表单到失败启动日志。
- Go 全量测试及 vet、相关包竞态、Wails 绑定生成、前端 191 项测试、类型检查、lint 与生产构建通过。保留现有工具链与构建告警。未连接用户的实际 MCP 服务，未运行桌面 E2E 或各平台系统凭据库联验。
