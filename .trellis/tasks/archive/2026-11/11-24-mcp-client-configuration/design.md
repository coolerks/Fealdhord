# 技术设计

## 连接身份与兼容

- 将稳定连接标识与显示名分开。以旧配置键作为既有连接的稳定标识，新连接生成独立标识。连接列表编辑、断开、重连及移除使用稳定标识。显示名支持中文、空格及常用分隔符，统一处理首尾空白和重复名。
- 既有未修改目标的连接保留原工具名映射、工具权限身份和 Bearer 读取路径。新连接使用稳定标识生成 ASCII 工具调用名。更换实际连接目标后重新计算工具权限身份。
- 迁移时保留旧 JSON 可读性并按字段补齐默认值。区分未设置和显式零次重试。凭据保存与配置写入沿用安全存储及失败回滚。旧 Bearer 留作兼容认证；HTTP 请求头中的显式 Authorization 控制本次使用的认证值。

## 传输与配置

- 扩展 `ClientConfig` 和桌面编辑表单。高级区默认折叠。请求头和环境变量用行式名称与值编辑。保留旧值、替换值和清除值通过明确操作区分，列表只回显安全元数据。HTTP 目标与代理参数可输入变量引用。
- 后端显式解析 `${NAME}`，在建连时读取系统环境，保留原始模板以支持后续重连。仅将值传入各传输所需字段；对展开后的命令、目录、URL、请求头和代理再次校验。秘密字面值使用系统凭据库，诊断不暴露请求头、代理密码和子进程环境值。
- STDIO 使用明确的参数数组、环境和工作目录创建进程。启动及 MCP 握手共用启动预算，成功后由 MCP 会话管理子进程生命周期。服务声明 MCP 日志能力时设置协议日志等级，默认警告；支持级别通过协议验证。普通 stderr 保持与协议 stdout 隔离。[MCP 日志协议](https://modelcontextprotocol.io/specification/2025-11-25/server/utilities/logging)
- HTTP 为每个连接构造独立 Transport。代理空白时直连，填写后通过标准 HTTP 代理支持可选代理认证。TLS 验证仅作用于 HTTPS 目标。连接超时限制初始化、发现及网络连接阶段，长期 SSE 使用会话生命周期。连接失败的重试仅针对可恢复网络错误，按配置限制次数；现有 SDK 的 SSE 重连上限同样取该值。工具调用在审批通过后使用独立超时，禁止因连接重试重放调用。[Go MCP SDK v1.7.0](https://pkg.go.dev/github.com/modelcontextprotocol/go-sdk@v1.7.0/mcp#StreamableClientTransport)

## 工具目录

复用协议分页迭代，移除 32 项截断。目录计数与单轮模型参数预算独立。连接级工具容量及重复游标有显式错误，连接替换须在发现和保存成功后提交。长目录继续使用精简工具入口，并提供可搜索的工具清单和权限项。[MCP 工具协议](https://modelcontextprotocol.io/specification/2025-11-25/server/tools#listing-tools)

## STDIO 日志查看

- 在启动子进程前接管 stderr，持续消费并按行保存。通过 SDK 的 `LoggingMessageHandler` 接收服务发送的 MCP 日志。协议 stdout 继续供 SDK 解析。日志等级用于 MCP 协议日志。stderr 保留来源标记，供不提供结构化日志的服务排错。
- 记录保存到按连接及启动尝试隔离的有界内存缓冲区，设置读取最近记录。限制单条记录和缓冲区总大小，标记截断，持续消费过量 stderr 以免阻塞进程。已保存连接断开后仍保留近期日志。首次连接尚未保存时，以临时尝试标识展示启动失败的日志。
- 写入缓冲区前遮盖该连接已知的秘密值和可识别凭据字段。配置及展开后的环境值只用于脱敏和启动，不拼入日志记录。日志在设置内以可选择的纯文本展示。仅在查看器打开时更新，关闭后停止读取。日志保留在应用进程内，并与工具执行审计保持独立。
