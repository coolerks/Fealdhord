# 完善 MCP 客户端连接配置

## 目标与现状

用户可配置 STDIO 和 Streamable HTTP 的基础及高级参数，使用中文连接名，并看到可发现的完整工具目录。当前 `internal/appagent/client.go` 用 ASCII 正则校验连接名，并在每条连接获取 32 项工具后主动退出迭代。两种传输共用 15 秒初始化时限。

## 需求与验收

1. 新增、编辑及重连可使用中文显示名称。编辑名称时保留同一连接、工具权限及凭据；原有配置继续可读。
2. 遍历工具列表的全部分页。在设置显示实际发现数量，超过 32 项时仍可查看、配置后续工具权限并从聊天调用。验收以跨多页、超过 32 项的模拟 MCP 服务为准。异常分页或超出目录容量时明确报告，避免显示已截断结果为完整目录。
3. STDIO 基础配置包含命令、逐项参数、环境变量和工作目录。高级设置包含启动超时、工具调用超时和日志等级。默认启动超时沿用 15 秒，工具调用默认 120 秒，日志等级默认警告。启动超时后清理子进程。日志等级用于支持 MCP 日志能力的服务，普通 STDIO 服务仍可连接。
4. Streamable HTTP 基础配置包含 URL 和自定义请求头。高级设置包含连接超时、工具调用超时、HTTP 代理地址和端口、可选代理用户名和密码、TLS 证书验证及连接重试次数。两种超时默认各 120 秒，连接重试默认 3 次，允许设置为 0。代理留空时直接连接。HTTPS 默认验证证书，HTTP 不适用。编辑后重新打开时显示已保存配置。
5. 在运行时用进程环境展开文本字段中的 `${NAME}`，包括 STDIO 环境变量值及 HTTP 的 URL、请求头值和代理字段。缺少变量时指出变量名。设置保留引用形式，错误和日志不暴露解析后的秘密。
6. 旧连接用原凭据成功重连。连接或保存失败时保留已保存配置和原可用连接。工具调用超时后报告结果状态，连接重试不重放工具调用。
7. 在「设置 → MCP 与权限 → 外部 MCP 连接」的 STDIO 连接行提供「查看日志」。显示该连接最近的子进程 stderr 和它发送的 MCP 日志，标明时间、来源及可用的级别。日志窗口打开时更新，断开后仍能查看本次运行的记录。新连接启动失败时可在编辑窗口查看该次尝试的日志。验收覆盖启动成功、启动失败、两个连接的日志隔离，以及日志内容的截断和脱敏。

## 范围

本次调整外部 MCP 客户端、连接编辑器、STDIO 日志查看，以及由工具发现影响的权限和聊天目录。STDIO 日志保留在本次应用运行的内存中。沿用既有 MCP 服务端配置、客户端授权、工具审批及执行审计。
