# 技术设计

- `internal/agentrun/stream.go` 使用上游聊天运行的取消上下文。调用次数和模型轮次继续约束循环。模型流各次尝试沿用协议适配器的空闲时限和单次总时限。可重试错误沿用退避和事件，回归覆盖工具续轮、逐次进度、实际启动次数以及取消。
- `internal/appagent/tools.go`、`user_question.go` 与 `plan_confirm.go` 通过现有决策通道等待，并保留上游取消与登记清理。审批队列同时服务桌面聊天和外部 MCP 已授权请求。外部请求保留两分钟待审批时限，以免桌面晚到的批准越过 HTTP 响应窗口。
- `internal/appagent/local_tools.go` 将 `shell` 的审批判断统一到现有注册表入口。保留命令参数解析、解释器验证和有效工作目录。核对内置工具、授权文章、MCP 加载及连接工具的权限执行入口。用户澄清和计划确认属于独立的交互步骤。
- 输入区以当前会话活动状态和成功的停止操作控制卡片，及时清理对应查询缓存，并复用消息终态同步，保留其他会话缓存和原草稿。独立审批弹窗使用同一队列。
- 数据库和绑定结构沿用现状。关闭应用终止内存中的等待。长时间待确认可能持续占用一个队列槽位，现有容量限制继续生效。
