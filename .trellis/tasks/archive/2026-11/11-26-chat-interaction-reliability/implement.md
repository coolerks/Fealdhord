# 实施与检查

1. 激活任务并补读相关开发规范。修改聊天运行时限、交互等待和共用权限判断。
2. 修复输入区停止与终态同步。检查重试进度从模型运行时、快照到界面的链路，补齐必要回归。
3. 用本地模拟模型验证持续输出不受整条回复时长截断，并覆盖续轮输出部分正文后超时的场景。断言配置为 5 时的实际请求、逐次事件、终态计数、正文衔接和工具仅执行一次。覆盖等待后决定与取消、Shell 权限模式及有关注册工具。前端验证停止后恢复草稿、清除卡片以及重试状态。
4. 运行受影响包的 Go 测试和竞态检查，运行前端类型检查、lint、单测和生产构建。按项目约束采用单元与集成测试。
5. 同步聊天规格、权限契约、当前状态及交接，按实际验证记录结果，提交本地 Git。
