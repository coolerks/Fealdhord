# RSS 订阅功能接线技术边界

详细契约见[统一方案](../11-05-phase3-rss/design.md)，本文件只界定子任务责任。

修改范围：frontend 的 lib API、订阅设置功能区、刷新命令和 Query 订阅。执行前置：ingestion／refresh／media 均通过各自验收后。共享 DTO／安全策略／事务所有权由父设计约束，禁止复制绕过网关的抓取器或让生成代码成为手改入口。

边界：在现有布局添加、发现选择、重命名、分类关联、归档恢复；刷新／取消／部分成功反馈，真实文章入库后可读，无示例数据。数据／API／设置变化同步实际规格；与其他子任务交换明确类型或提交后钩子，不引入循环依赖。独立提交为回退点，已有生产数据和状态必须保留。
