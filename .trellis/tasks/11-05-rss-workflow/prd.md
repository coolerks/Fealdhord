# RSS 订阅功能接线

## 目标与范围

实现 Phase 3 的独立交付：frontend 的 lib API、订阅设置功能区、刷新命令和 Query 订阅。整体需求与范围见[父任务](../11-05-phase3-rss/prd.md)，保留暂停视觉调整、中文文档、主会话执行和分部分提交授权。

## 验收

在现有布局添加、发现选择、重命名、分类关联、归档恢复；刷新／取消／部分成功反馈，真实文章入库后可读，无示例数据。具体策略沿用父任务设计与既有 RSS／安全／媒体契约，不把其他子任务规划写成本任务现有能力。

## 依赖与边界

执行前置：ingestion／refresh／media 均通过各自验收后。不新增 AI、OPML、完整分页或视觉重设计。当前规划完成，待父阶段最终评审。
