# 技能外观与聊天输入体验

覆盖父任务 R3 至 R5。

- 用途不同的斜杠操作使用独立图标，技能项采用技能的自定义外观或默认图标。当前 `ChatSlashMenu.tsx` 有各操作的图标输入，`AnimatedGlyph` 未指定语义时使用默认图形，需要核对各动画模式的实际输出。
- 手工新建、ZIP／Markdown 导入预览和编辑保存均支持图标和颜色。复用 `IconPicker`、`ColorPicker` 和 `CustomIcon`。导入预览确认后的个性化信息持久化，旧记录按默认图标读回。
- 显式选择的技能属于本次发送。发送后把技能身份和展示信息保存在对应用户消息，显示于正文前。自动发现的技能无需伪造为用户选择。队列收录时保存独立快照，执行或转引导时继续携带。发送失败保留可重试信息。
- 当前 `ChatDialog.tsx` 持有 `selectedSkills`，普通发送可传给后端，队列、引导和消息 DTO 需要同步。回归覆盖连续两次发送不继承前一次选择、重开历史、发送失败、排队及引导。
