## 验收标准

- M1：输入框、只读字段、文本选区、文章和空白区域按上下文展示有效分组；无空组、冗余标题或首尾分隔线。每项有图标，已生效快捷键按平台格式末尾对齐；未绑定项不伪造快捷键。
- M2：指针停留时动画完成后自动归位；移出不截断；快速进入不排队、不并行，完成后可重新触发；键盘聚焦亦可播放且不与鼠标重复。
- M3：使用官方动画，不用统一跳动或自创轨迹替代；静态与动态图形、尺寸、笔画一致，切换不闪换图标。
- M4：覆盖清单无遗漏；菜单整行、按钮整按钮触发，被动图标自身 hover；禁用项不播放，不给被动图标增加按钮角色或 Tab 停靠。
- M5：关闭／系统减少动态时菜单和页面一致；模式切换、卸载使旧回调失效。每目标最多一条播放链，静置无循环／轮询；列表仍虚拟化。
- 保留文本选择、剪切复制粘贴快照校验、只读限制、焦点恢复、收藏／已读持久化、菜单键盘导航与现有快捷键；可访问名称和角色稳定。
- 相关组件回归、类型、lint、前端和 macOS 构建通过；必要的真实运行核验单独记录，截图不能证明动画流畅，不声称未测平台通过。

## 范围边界与三方体验

本轮覆盖应用内图标；macOS 系统菜单继续交由 AppKit，系统交通灯及系统拥有的标记不伪装为可动画控件。不新增快捷键、RSS／AI、数据库或业务 API，不做全应用 E2E。

用户体验以菜单扫读和自动归位改善；开发体验以统一播放和命令呈现改善；AI Agent 体验以稳定命令 ID、语义分组和可访问名称改善。三者共同以保留现有回归为门禁。
