# Phase 4：完整基础阅读器

## 目标与授权

用户要求规划后直接实施，已确认创建本任务。让全库文章可分页搜索／筛选，提供真实分类与订阅导航、安全 HTML 阅读和 OPML 迁移。暂停视觉调整；中文文档、禁止子代理、非必要不做 E2E、按完成部分提交。

## 已确认事实

Phase 3 RSS 已完成并归档。当前 LibraryService 只返回最新 500 篇，前端筛选不是全库搜索；分类仓储已有来源优先级，但缺管理服务；Reader 只有纯文本；OPML 未实现。详见 research.md 的源码依据。

## 范围与验收

1. SEARCH-01–03／API-01：统一 ArticleQuery，数据库筛选、稳定时间游标／全文排序游标、取消与过期恢复；中文／英文／混合／标点查询安全；首屏不受最新 500 篇限制，继续加载无重复，旧查询不能覆盖新查询。
2. CAT-01–03：分类树创建／编辑／移动／排序／删除预览，深度与重名约束；有效成员、手动排除／恢复自动；订阅与分类导航、全库未读计数，不重复计数。
3. READER-01–03：安全订阅 HTML、受控 Reader 提取／缓存／取消、失败保留原文、系统浏览器原文入口、可配置自动已读与字体；禁图不请求远端资源。
4. OPML-01–02：原生文件授权，受限解析预览／确认事务导入，空 Folder／多分类／重复 URL 保真，安全树形导出；取消零写入，失败不破坏现有文件。
5. 各部分有可重复的相关测试，类型／lint／生成绑定／原生构建与中文契约同步，直接本地提交；记录真实限制，不宣称未运行的平台或性能通过。

## 范围外

AI／Agent／Skills／MCP、视觉重做、动态活跃度调度、永久擦除用户历史、正式发布签名和五平台实机验收。不以重复流程阻塞功能。

## 执行顺序

library-query → library-navigation → reader-content → opml-transfer。父任务负责联验和真实状态，四部分依次实现、检查、提交；授权覆盖本范围，暂无需要用户决策的开放问题。
